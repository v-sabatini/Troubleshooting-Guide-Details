## Upload & setup (owned by FLEX/DOC)

- **Manual upload:** pages/links sent via email; once on the SFTP, select all pages from the appropriate SFTP folder **in both languages** → Auto-group → **ensure French pages are updated to the correct language** → Save & Confirm. Do NOT process internally.
- **Pricing Zone:** create zones **by language** — one English, one French. Add all applicable stores using the **"BASE 2025" store set** to both zones.

### Setup QC
- Confirm all pages uploaded correctly (Pricing Zone tab → Items View). **Risk:** confirm no SFTP pages left un-uploaded.
- Confirm flyer dates (first page); complete thumbnails (Standard 4); **No Theme, No External Run Name**.

## ⚠️ Common errors / risk items (retailer-specific)

- **Bilingual flyer** — ensure French pages are set to the correct language during upload.
- **SFTP upload risk:** confirm there are no un-uploaded pages in the SFTP.

## QC specifics

### Box Draw (Low; Auto-Box OFF, Box QC bot OFF)
- Linking Document required (Box Draw/Box QC-specific).
- **Include:** retailer logo, social media, special weblinks. **Exclude:** coupons, packaged deals, sign-up page.
- Box every single item; box the header on each page; **social media icons and the Bentley logo on the FIRST and LAST page must be boxed.**

### Tag / Tag QC (Low; Auto-tag OFF)
- Linking Document required.
- **Include:** name, pre/postfix, valid dates, description, price, sale story, categories, disclaimer, original price, URLs, Brand. **Exclude:** SKU.
- Link each product with the appropriate URL from the link document; header URLs match by page title; logo, shopbentley.com, and social media URLs are on the linking document.

### Image QC
- Standard Image QC — PDF preferred if clean, otherwise cutouts accepted.

## FQC (Flyer Review type: Lite; owned by DOC)
- Confirm dates (per PDF) and availability toggles; thumbnails correct incl. retailer logo.
- Standard checks: all items boxed and tagged, spotchecks complete (20% of pricing zones), previews published correctly and clickable, sessions completed accurately, geography correct.
- Check Items without URL — confirm anything missing is not on the URL document.
