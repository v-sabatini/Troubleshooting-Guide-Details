## Files & schedule

- **Files arrive:** ad-hoc. Avail/Valid dates often communicated via email or found on the last page.

## Upload & setup (owned by Flex)

- **Manual upload.** ⚠️ **On upload, ensure there are a minimum of 6 products if only 1 page is provided — if fewer than 6, flag ASAP.**
- 1 PZ = Base; add all stores.
- Flyer Details: check avail + valid dates; Internal Run name = title of flyer; no theme.
- Thumbnails: Standard 4, no custom tile.

## QC specifics

- **Box Draw (Low; Auto-Box ON, Box QC bot ON):** no linking doc. **Include retailer logo and sign-up page**; exclude coupons, packaged deals, social media, special weblinks. Box items as they appear (text boxes if needed). **Only box newsletter sign-ups / store info / retailer websites IF a URL document is attached** — if no URL doc, do not box these.
- **Tag / Tag QC (Low; Auto-tag OFF, PDF image auto-selection ON):** linking doc required (tag-specific), **no brand**. **Include** name, description, price, sale story, categories, original price. **Exclude** pre/postfix, valid dates, SKU, disclaimer, URLs. **Use cutout images.**
- **Image QC:** PDF preferred (Ontario only); otherwise item cutout.

## Final QC / go-live notes (owned by DOC)

- Pre-Final QC: sessions and vendors complete; thumbnails done (Standard 4); geography should have no changes unless new stores added.
- **Flyer Review type: Lite** (owned by Flex).
