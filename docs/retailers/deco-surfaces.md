## Files & schedule
- **Files received:** Monday.
- **Publication:** Available From Monday / Valid From Tuesday → Available To Monday / Valid To Tuesday. **No preview day** — confirm dates from email and last page of flyer.
- **Linking document:** Yes — attach to all vendor tasks (also provided in the files email; no manipulation needed). Used as the URL source for tagging and as a boxing guide.

## Upload & setup (owned by Flex)
- Manual upload: Pages → Edit → upload all files for the flyer → **toggle language EN and FR per file** → Auto Group → do not process internally.
- **Two pricing zones: ENG (all English pages) and FR (all French pages); add all stores to both.**
- **Geography:** no stores added. Attach linking doc to all vendor tasks; confirm sessions ran.
- Edit Details: Internal Run Name "Mon, dd, yyyy"; no preview start date; available everywhere; no theme. Leg heights **45/35**; QC thumbnails Standard 4.

## Box Draw (Low — Auto-Box ON, Box QC bot OFF; linking-doc required)
- **Include:** retailer logo, sign-up page, social media, special weblinks. **Exclude:** coupons, packaged deals.
- Box separately every item with a price, a sale/percentage-off callout, or an individual sale callout. **Each item with a URL in the linking document should be boxed.**

## Tag / Tag QC (Low; Auto-tag OFF; linking-doc required)
- **Include:** name, pre/postfix, valid dates, description, price, sale story, categories, disclaimer, original price, URLs. **Exclude:** SKU. Brand used for Box/Tag.
- **URL** comes from the linking document attached to all vendor tasks. Example fields: Name, Description, URL, Current/Original Price, Postfix (e.g. "sq. ft"), Sale Story (e.g. "16% OFF"), Percent Off, Categories (Flooring), Google Categories.

## Image QC
- **PDFs are rarely clean → cutouts are typically preferable.** May need to click "Generate Data Piping Groups".

## FQC (owned by DOC)
- Geography: no stores added; linking doc attached; sessions run; check everything boxed; horizontal & vertical scroll.
- Page categories: all pages except Page 1 (if available).
- Edit Details: no preview day (confirm dates from email + last page); internal run name "Mon, dd, yyyy"; available everywhere; no theme. Leg heights 45/35; thumbnails Standard 4.
- **Flyer Review type: Lite.**

## Out-of-processing
- Page swaps are standard (baseline page-swap video). Black Friday comms docs provided for 2024/2025.
