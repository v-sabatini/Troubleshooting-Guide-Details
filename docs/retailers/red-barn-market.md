## Upload & setup (owned by Vendor; Flex updates the setup/setup-QC tracker)
- **Manual upload:** Pages tab > Edit > select the lowercase file for that week > Upload > Auto group > Save and complete.
- Flyer creation: build **one pricing zone with all pages**; assign all stores.
- Complete the setup QC checklist.

## QC specifics
- **Box Draw (Low; Auto-Box ON, Box QC bot OFF):** **include retailer logo, sign-up page, social media, special weblinks**; exclude coupons, packaged deals. Box all items; **box the social media buttons in the bottom-left corner of each page**; box any "Click here" buttons.
- **Tag / Tag QC (Low; Auto-tag OFF):** include Name, Description, SKU, Price, Sale Story, Categories, Disclaimer, Original Price; Brand is Box Draw/Box QC specific; exclude Pre/Postfix, Valid Dates. **URLs: only add URLs to the social-media icons at the bottom of each page — do NOT add URLs to products.**

## Post-processing
- **Item Category QC (Flex):** ensure items have an analytical category; page categories on all pages except the first.
- **Item Image QC (Vendor):** clean white PDF images where possible, else cutout.
- **URL/Links QC (Flex):** tag all social-media icons at the bottom of the page — Facebook (facebook.com/RedBarnMarkets), Twitter (twitter.com/RedBarnMarkets), Instagram (instagram.com/redbarnmarkets/).
- **Ad-hoc QC checks (Flex):** check Geography tab (flag any discrepancy vs. last week to FT team); open both previews, click items to confirm interactive; double-check dates; leg heights 50/40; Basic 4 thumbnails.
- **FQC (Flex):** complete the FQC checklist.
