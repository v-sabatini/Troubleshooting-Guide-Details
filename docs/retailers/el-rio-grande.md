## Files & schedule

- **When files arrive:** Thursday. Available From Wednesday · Valid From Wednesday · Available To Tuesday · Valid To Tuesday.

## Upload & setup (owned by Vendor)

- **Manual upload** (files usually dropped Thursday). Page naming: `Ers1_A_R01` → Ers# = page number, R0# = version. "ALL" in the filename means the page is the same across versions (upload one copy).
- **Only upload pages labelled `P0001, P0002…`** — do NOT upload files without page numbers.
- Create **three pricing zones V1, V2, V3** and insert their respective pages. Add all V1 stores to V1, V2 stores to V2, V3 stores to V3.
- **Setup QC:** available on Flipp & Distributed only; **key message "Our Deals. Your Savings."**; thumbnails Standard 4 (page 2 is wide — don't fill the entire second page with the thumbnail); legibility heights **45/30**.

### ⚠️ Common errors / risk items (retailer-specific)

- **3-Day Sale items** (bottom of page 1): every item in the 3-Day Sale section must have **Sale Story = "3 DAY SALE"** plus **Item Valid From / Item Valid To** dates matching the banner callout — not the full-flyer dates.
- **Store #7:** often not listed in page names, but **must be included in Pricing Zone V1** — add all V1 store-set stores to PZ V1 **including Store #7**; do NOT remove it.

## QC specifics

- **Box Draw (Low; Auto-Box ON, Box QC bot ON).** No linking doc. Box all items with prices (text boxes when needed). **Include** packaged deals. **Exclude** coupons, retailer logo, sign-up page, social media, special weblinks.
- **Tag / Tag QC (Low; Auto-tag ON; PDF Image Auto Selection ON).** No linking doc. Tag all fields as in the flyer. Include name, pre/postfix, valid dates, description, SKU, price, sale story, categories, disclaimer, original price. Brand handled via Box Draw/Box QC. URLs = N/A.
  - **Name:** the **English** (or non-bold) version of the item; brand if applicable.
  - **Description:** the **Spanish** name of the item. If only one language is available, put the larger/bold text in Name and the smaller/non-bold text in Description.
  - **SKU:** use the flyer-provided SKUs if available.
  - **Valid dates:** watch for the "3-DAY SALE" box on page 1 (a section, not the whole page/publication).
  - **Disclaimer:** only enter if it's inside the drawn box; ignore disclaimers at the bottom of the page.
- **Image QC:** prioritize clean **white-background PDFs**; avoid lifestyle/background PDFs (choose the cutout); plated-item images OK if they match the flyer; if the PDF has a large black shadow that doesn't match, choose the cutout.

## Final QC / go-live (owned by Vendor)

- Edit Details: available on Flipp and Distributed only. Thumbnails Standard 4. Page categories (no category on page 1).
- **Check the 3-Day Sale section on page 1 for BOTH versions** — each item has valid dates matching the 3-Day Sale banner and Sale Story = "3 DAY SALE".
- Complete FQC checklist (certain overview errors may be ignored — Save and Complete if they're the only ones).
- **Flyer Review type: Lite** (owned by FLEX).
