## ⚠️ Common errors / risk items (retailer-specific)

- **Different items displayed together must be boxed separately** — they have different SKUs and links. Examples: different cooking products with different prices; Billy Bee and Beaver products at the same price; Bello Collection items at the same price (facecloths/hand towels come in multi-packs, bath towel does not).
- **Box items even with no price** if they have a sale/discount — e.g. box and tag all items on a "We pay the TAXES" page with that sale story.
- If a product has multiple sizes/versions, **box them together if they share the same URL**; if URLs differ in the linking doc, box separately.
- **Two links per item** (URL field + Item URL field), EN and FR respectively — easy to forget.

## QC specifics

### Box Draw (Low complexity; Auto-Box ON, Box QC bot OFF)
- Requires Box Draw/Box QC-specific linking document.
- **Include:** retailer logo, sign-up page, social media, special weblinks. **Exclude** coupons and packaged deals.
- Use text boxes if necessary.

### Tag / Tag QC (Low complexity; Auto-tag OFF; PDF Image Auto Selection ON)
- Requires Tag/QC-specific linking document.
- Include brand, name, pre/postfix, valid dates, description, SKU, price, sale story, categories, disclaimer, original price, URLs.
- Custom field: **Item URL**.

### Image QC
- White-background images preferred; if no clean white background is available, a cutout is acceptable — **disregard flags when cutouts are selected**.

## Cloning process (NEW — DOC)
- Clone the regular weekly flyer as a **hosted-only** version.
- Remove the regular weekly pages from the clone — **only the WEB pages remain** in the pricing zones.

## FQC / go-live notes (owned by DOC)
- **Flyer Sorting order:** 1. Regular flyer / Circulaire régulière, 2. Web Flyer / Solde Web, 3. Summer catalog / Catalogue d'été. Preview shows after the currently live flyer.
- Complete auto-stacks; [FLEX] items without URLs — double-check against linking doc.
- Leg heights **45–35**; Image QC prefers clean PDFs (~70–80% clean images).
- **Four Thumbnails 2121 — include the logo:** Thumbnail 1065x800, Stock_premium, Storefront_carusel_premium, Storefront_carusel_organic.
- Pricing zones: all boxed (item view); horizontal/vertical preview (interactive + linked out); [FLEX] spot-check links.
- Page categories: one per page **except Page 1**.
- Check sessions and geography; external run name = "Flyer".
- Ensure all pages appear correctly in vertical preview (WEB flyer pages can appear blank).
