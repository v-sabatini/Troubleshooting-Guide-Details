## Files & schedule
- **Files arrive:** Thursday.
- **Cadence:** Available From Tuesday; Valid From Wednesday → Available/Valid To Tuesday.
- **Preview date: 1 day before go-live at 3:00 AM.**

## Upload & setup (owned by Vendor)
- **Manual upload.**
- Shorten page names (some are too long to see); **confirm the grouping number — pages will NOT auto-group.**
- **One PZ (Base)**; add all stores (**29**).

### Setup QC (owned by Vendor)
- In Details, set preview date (one day before go-live at 3:00 AM).
- Check Autoboxes look good; complete Setup QC; 4 standard thumbnails.

## ⚠️ Common errors / risk items
- **Pages will not auto-group** — confirm the grouping number manually on upload.

## QC specifics
- **Box Draw (Low; Auto-Box ON, Box QC bot OFF):** **Include** coupons, retailer logo, sign-up page, social media, special weblinks; **exclude** packaged deals.
- **Tag / Tag QC (Low; Auto-tag ON):** Brand box-draw/QC specific. Include name, description, price/original, pre/postfix, valid dates (if applicable), categories, sale story, disclaimer, URLs; **SKU N/A.**
- **Image QC:** standard.
- **Spotchecks:** reference Tag/Tag QC instructions.

## Post-processing (Item Category/Image/URL/SKU QC owned by Flex; Ad-hoc by DOC)
- Instructions not filled in in the OneGuide beyond the standard placeholders.

## FQC (owned by Flex)
1. **Mark Items Store Only** (Sessions → "Mark Items Store Only"; should read full 100%).
2. **4 standard thumbnails (2,1,2,1).**
3. Set "no theme".
4. Check previews + sessions (rerun page stitching for images if needed; check back 15–20 min later).
5. FQC checklist.

## Flyer review
- **Type: Lite.** Owned by Flex.

## Out-of-processing
- **Page Swap:** standard baseline page swap.
