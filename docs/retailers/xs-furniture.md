> **Note:** This OneGuide covers the Surplus Furniture & Mattress Warehouse / XS Furniture account; instructions and links reference the Surplus Furniture storefront.

## Files & schedule

- **Files received:** Monday.
- **Cadence:** Available From Monday, Valid From Sunday; Available To Monday, Valid To Sunday.
- **Preview date:** set 2 business days before live date.
- Flyer run dates are in the **links document** (`.xlsx`) attached to vendor tasks.

## Upload & setup (owned by Vendor)

- **Pages → Edit →** find the folder path matching the flyer run name.
- Upload all pages → **Autogroup** → Save and complete.
- Attach the links document (`.xlsx`) to all vendor tasks.

### Setup QC
- **Available = Everywhere**; External Name from the email callout or link sheet; **No Theme**.
- **Thumbnails = Standard 4**, plus a **custom tile** for Storefront Carousel Premium & Storefront Premium (applied to all PZs): under thumbnail QC → Choose file → select jpg → Override thumbnail → Apply to all PZs → refresh.

## QC specifics

### Box Draw (Low; Auto-Box ON, Box QC bot OFF)
- Linking document required (Box-Draw specific).
- **Include:** retailer logo, sign-up page, social media, special weblinks. **Exclude:** coupons, packaged deals.
- Social media must be tagged/linked: Facebook, Instagram, YouTube, TikTok (Surplus Furniture Canada handles).

### Tag / Tag QC (Low; Auto-tag OFF)
- Linking document required (Tag/QC specific).
- **Include** brand, name, pre/postfix, description, SKU, price, sale story, categories, disclaimer, original price, URLs. **Exclude valid dates.**
- For all **non-purchasable items that include links**, set display type to **'Link'** and input the corresponding URL from the Linking Sheet.

### ⚠️ Common errors (retailer-specific)
- **Current Price must reflect the "main" advertised price, not one of the listed prices.** Example error: current price entered as 399 when the main advertised price is 549 — the listed prices/sizes belong in the **Sale Story**, not Current Price.

### Image QC
- **No image QC for this retailer.**

## Post-processing / links QC (owned by Flex)
- Overview → Information/Reports → **Items without URL**; work through them with the link sheet. One PZ's links can be reused across all zones (they're identical).

## Final QC / go-live notes (owned by Flex)
- Vendor tasks completed.
- **Set Cutout Images:** Custom Actions → Set Cutout Images → enter Flyer Run ID → Complete Action.
- Check Items Without URL against the linking sheet: update links that exist in the sheet; link the rest to the retailer website.
- **Mark Items In Store Only** — only *after* checking items without a URL.
- Pricing Zones: horizontal + vertical check.
- **Page categories** (OS can't tag — add manually, ≥1 per page): Mattresses = Bedding; Bed Frames & Dressers = Bedroom.
- Edit Details: dates from the email; Available = Everywhere; External Name = link-sheet callout; No Theme (usually).
- **Leg heights = 55/45.** Standard 4 thumbnails **+ custom tiles** (risk: ensure custom tiles are added). No image QC.
- **Flyer Review type: Lite.**

## Out-of-processing
- **Page swap:** standard — use the baseline page-swap video.
