## Files & schedule

- **Files received:** Thursday.
- **Publication:** Available From Tuesday; Valid Wednesday → Tuesday (normally a 1-day preview, not always).
- **Linking document:** Yes — the `Digital Flyer.xlsx` PDF linking document from SFTP, attached to all vendor tasks.

## Upload & setup (owned by Vendor)

- Manually upload all pages (file name should match the flyer run name), auto-group, Save, Save & Complete.
- **1 pricing zone — `BASE`**, add all stores.
- Check SFTP for pages not uploaded — confirm with the full-time team if they should be added.
- Attach the linking doc (`Digital Flyer.xlsx`) to all vendor tasks.
- **Setup QC:** geography tab (no stores added); PDF dates vs flyer run dates (usually 1-day preview — check with full-time team if unsure); standard 4 thumbnails.

### ⚠️ Common errors / risk items (retailer-specific)

- Watch for **multiple products** in one block — box each item individually even when multiple items appear in the same product block.
- Verify SFTP has no un-uploaded pages before proceeding.

## QC specifics

- **Box Draw — Low complexity. Auto-Box OFF, Box QC bot OFF. Linking doc required.** Exclude coupons, packaged deals, retailer logo, sign-up page, social media, special weblinks. Box each item individually.
- **Tag / Tag QC — Low. Auto-tag OFF. PDF image auto-selection ON. Linking doc required. Valid dates and SKU excluded.** Include name, pre/postfix, description, price, sale story, categories, disclaimer, original price, URLs.
- **Image QC:** PDF image preferred; cutout otherwise.

## FQC / go-live (owned by Flex)

- **Check URLs:** open the linking doc attached to vendor tasks, review every link on each page; add comment "All links checked" when done. Items without URL.
- No theme; spotchecks if required; thumbnails standard 4 (stock premium, storefront carousel premium & organic); Category QC (everything has a category); **do NOT do Image QC** at FQC; check pages for missed boxes.
- **Flyer Review type: Lite.**
