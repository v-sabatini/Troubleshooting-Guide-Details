## Files & schedule
- **Files received:** Monday (uploaded Wed/Thu). Reach out Friday afternoon if files still not received.
- **Publication:** Available From Thursday / Valid From Friday → Available/Valid To Thursday.
- No linking document.

## Upload & setup
- Manual Upload: Pages → Edit → Upload from FTP → select pages from the corresponding Month folder → Auto-group → Save & Complete.
- File names include week number and page number. Files are **English only**.
- **Page 4 + 5** are provided as a spread plus individual pages — **upload the individual pages, not the spread.**
- **One pricing zone: base; add all stores (there are 9).**
- Let sessions run; auto-box draw kicks off; begin Setup QC.

## Box Draw (Low — Auto-Box ON, Box QC bot OFF)
- **Include:** retailer logo, sign-up page, social media, special weblinks. **Exclude:** coupons, packaged deals.
- Box all items separately (with text boxes where needed); **anything with a price gets a box.** Draw neatly.

## Tag / Tag QC (Low; Auto-tag OFF; PDF image auto-selection ON) — always include Category
- **Include:** name, description, SKU, price, sale story, categories, disclaimer, original price, URLs. **Exclude:** pre/postfix, valid dates. Brand used for Box/Tag. (Note: doc also states SKU/URL "N/A for this merchant".)
- **Name:** only **bolded** words; match the flyer's capitalization exactly. **Most of the time do NOT put measurements in the Name** — they go in Description (exception: when multiple measurements are in one box, the bolded item's measurement goes in Name).
- **Description:** non-bolded words + measurements. **Do not include "With Card"/"Without Card"** — that goes in Postfix.
  - Use "Or" before non-bolded items only when they are alternatives, not just varieties.
- **Postfix:** enter "With Card. Without Card $xx.xx" if applicable.
- **Promotions/offers:** tag with link deciccoandsons.com. Tag "Follow us on Twitter and Instagram" separately with the Twitter link. Add links for jobs.deciccos.com and stores.deciccos.com.
- **Images:** always choose the most relevant & cleanest PDF image.

## FQC (owned by Flex)
- Mark Autostack spotcheck complete; leg heights **60/40**; dates correct per Page 1; thumbnails Standard 4 + first_page_thumbnail_400w.
- **Page Categories:** leave Page 1 blank; variety of foods → Grocery; meat page → Meat; also Seafood, Produce, etc.
- **Flyer Review type: Lite.**
