## Files & schedule

- **Files received:** Thursday, variable times (normally >5 business days lead time).
- **Publication cadence:** Available From Thursday → Available To Thursday; Valid From Friday → Valid To Thursday.
- **Preview date:** always set to the following Monday.
- **Linking Document:** Yes (Modified Ad Sheet).
- **Coupons:** largely phased out (retailer uses their own in-store barcodes); occasionally still receive coupon ads, processed as usual.

## Upload & setup (owned by DOC)

1. Add a Monday preview date on the flyer shells.
2. Manual upload (folder labelled by live dates); sort pages 1–7.
3. **Preview 01 page:** if present, put it in the flyer and set a trigger for the other Page 01 page to replace it once the flyer is valid. Preview 01 shows only during the consumer preview day (Thu 11 PM), then triggers out for Page 01 when valid (Fri 10 AM).
4. Manually upload the recurring **ODD Sign-up page** (second-to-last position) and **Category page** (last position).
5. One PZ = **BASE**; add all stores.
6. Download the Modified Ad Sheet and attach to all vendor tasks.
7. Complete Setup QC (Standard 4 thumbnails).

## ⚠️ Common errors / risk items (retailer-specific)

- **Price discrepancies at live dates:** the retailer sometimes sends new prices different from the PDF / ad sheet. If a wrong price is flagged at live dates, **check the price on the website before changing it** — original/current price should match the website. (Note for weekend/part-time team; not for OS/DSP.)
- **Original price sourcing:** use the ad-sheet regular price unless it conflicts with the website — then use the website's regular price. If a regular price is on the ad sheet but not the website, use the ad sheet.
- **Liners** (text-only items in small boxes) are easily missed — usually at the bottom of grouped items; tag the correct brand from the ad sheet/website. Do NOT assume a liner matches the brand of the item above it.
- **URLs must lead to a Product Page, not a Search Page.** Verify the link's product image, brand, name, quantity, and regular price match the flyer.
- **SVP (Super Value Price)** with no separate original price → enter only the Current Price, no Original Price.
- **Disclaimers are often missed** — pay close attention (usually small font in brackets).
- For Youth/Women's/Men's/Adult options, check every SKU in the ad sheet — they usually have different URLs.

## QC specifics

### Box Draw (HIGH; Auto-Box ON, Box QC bot OFF)
- Linking Document required (Tag/QC-specific).
- **Include:** coupons, retailer logo, sign-up page, social media, special weblinks. **Exclude:** packaged deals.
- Box each item with a separating feature separately; draw as much of the item as possible without overlapping. Box shoes/knives individually.
- Two boxes when one image but multiple brands shown (box the item + the far brand name). Men's + Women's shown as two pairs → separate boxes; one shoe shown with "Men's or Women's" listed → box the shoe + the text of the non-shown gender.
- "Combo" in the product name → one box. Box ALL coupons. Do NOT box generalized sales stories. Online Spotlight: box items separately from the "Buy Now" button. No text boxes; no overlapping.

### Tag / Tag QC (HIGH; Auto-tag OFF; PDF Image Auto Selection ON)
- Linking Document required (Tag/QC-specific).
- **Include:** name, pre/postfix, valid dates, SKU, price, categories, disclaimer, original price, URLs, Brand. **Exclude:** description, sale story.
- **Do NOT enter a Sale Story for any item.** One brand only in Brand field. Name: only characters in the flyer, no extra hyphens/quotations.
- **SKU:** add to every applicable item; use the long SKU ("Item #" column); if no/incorrect link, try the short SKU ("SKU #" column).
- Multiple prices in one box → read the bolded titles above the prices and tag accordingly.
- Valid date overrides: enter page-specific valid dates where noted.
- **Analytics categories** (assign one): Apparel, Footwear, Team Sports, Watches/Sunglasses, Games, Outdoor, Golf/Racquets, Fitness, Sporting Arms, Electronics. Both Category Highlights and Analytics Categories must always be assigned (they need not match).
- Social media links named per the guide (Big 5 Sporting Goods, Facebook, Twitter, Yowza, Pinterest, Instagram).

### Image QC
- Datapiping is completed for this account, aimed at 100% datapiping for clean images.

## FQC / Pre-FQC
- **Pre-FQC (owned by Flex):** Tuesday mornings, doc posts the flyer run in `#3fl-big-5`. Confirm boxing/tagging; Standard 4 thumbnails; handle the 2 page inserts (ODD page 2nd-to-last, Category page last) — delete auto-drawn boxes, copy items from the previous flyer, verify Preview 01 / Page 01 CTA links.
- **Data piping:** keep running data piping to reach the highest %. Troubleshooting: if a URL 404s, that's acceptable — leave the item as is (no need to data pipe).
- **FQC (owned by DOC):** available everywhere (+theme if applicable); ledge height 40/30; Standard 4 thumbnails; confirm data piping at 100%; Image QC (only red images — select clean PDFs); storefront spot-check (slice + pagination); mark wayfinding complete; check geography; media tagged (usually page 1); footer links applied; item search postfix "each" removed from shoes. Provide preview Wednesday AM.
- **Post-FQC (owned by Flex):** retailer sends corrections by email for both ads (Thursday mornings); paste into a Google doc, bold page numbers, link flyer run IDs, share in `#3fl-big-5`. "s/b" = "should be". When updating a link/SKU, press "fetch SKU" after applying the link. Ignore "See More Info" button glitch flags.
