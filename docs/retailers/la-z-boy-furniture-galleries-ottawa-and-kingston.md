**Bilingual** (separate English and French pricing zones).

## Files & schedule

- **Files arrive:** Monday (retailer emails to confirm files uploaded to FTP + flyer run dates).
- **Cadence:** Available From Tuesday / Valid From Monday.

## Upload & setup (owned by DOC)

- **Manual upload** (2–10 pages); English and French files (clearly labelled).

### Setup QC (owned by Flex)
- **2 pricing zones — 1 English, 1 French.** Add all stores to both languages unless told otherwise (e.g. a closing/opening sale may be a single store).
- After mass upload, check right-to-left starting at Geography → vendors → sessions.
- Flyer Details: check avail + valid dates (should be the same); Internal Run name = title of flyer; available everywhere; no theme. Thumbnails Standard 4.

## QC specifics

- **Box Draw (Low; Auto-Box ON, Box QC bot ON):** no linking doc. **Include retailer logo and sign-up page**; exclude coupons, packaged deals, social media, special weblinks. Box each item with a price.
- **Tag / Tag QC (Low; Auto-tag OFF, PDF image auto-selection ON):** linking doc required (tag-specific), **no brand**. **Include** name, description, price, sale story, categories, original price. **Exclude** pre/postfix, valid dates, SKU, disclaimer, URLs. **Use cutout images.**
- **Image QC:** PDF preferred; select cutout if no clean white background.

## Final QC / go-live notes (owned by DOC)

- Pre-Final QC: sessions/vendors complete; **language settings correct**; thumbnails Standard 4; geography matches previous week.
- **URL check:** review "Items without URL" and ensure links are applied to all items.
- **Flyer Review type: Lite** (owned by DOL).
