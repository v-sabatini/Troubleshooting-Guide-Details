## Files & schedule
- **Files received:** 5 days before launch.
- **Publication:** ad-hoc — Available/Valid dates per the PDF.
- No preview date, no linking document.

## Upload & setup (owned by Vendor)
- **Manual upload:** Pages → Edit → select pages from SFTP. **Folder is named by the flyer valid date — always use the *lower-case* folder; do not upload the Upper Case folder.** Confirm & Upload → Auto-Group → Save & Complete.
- **One pricing zone "Base"; add all stores** → Save & Complete.
- **Setup QC:** confirm all pages uploaded — the only file remaining in the SFTP should be the multi-page PDF (Upper Case name, not ending in "P####"); if pages were missed, flag the FT team. Confirm valid dates match Page 1. Standard 4 thumbnails. **Geography: 0 changes to stores/FSAs — flag ANY change to the FT team.** Available on all platforms.

## Box Draw (Low — Auto-Box ON, Box QC bot OFF)
- **Exclude everything:** coupons, packaged deals, retailer logo, sign-up page, social media, special weblinks.

## Tag / Tag QC (Low; Auto-tag ON)
- **Include:** name, pre/postfix, valid dates, description, price, sale story, categories, disclaimer, original price. **Exclude:** SKU, URLs. Brand used for both Box/Tag.
- **Image:** always select a clean PDF if available.

## Pre-FQC / FQC (owned by Vendor)
- Dates correct per PDF; available everywhere; thumbnails include retailer logo; all items boxed/tagged; previews clickable; **Geography consistent with last week — immediately flag 100% of discrepancies to the FT Ops team** (does not block work).
- **Flyer Review type: Lite.**
