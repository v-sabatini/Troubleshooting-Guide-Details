# OneGuide — Retailer Index (493 retailers)

> **What this is:** The master directory of **per-retailer processing
> instruction guides** ("OneGuides"). The source of truth is the Confluence
> **OneGuide** page (space **VEN / Vendor**, page `10823336187`), which links out
> to **one Google Doc per retailer/banner**. This file mirrors that directory so
> the knowledge base has a complete map of which retailer guides exist and where.
>
> **Retailer processing articles** built from these live in `docs/retailers/`.
> Only some are converted so far — see the KB index for status.

## ⚠️ Handling notes (important)

- The source Google Docs contain **credentials/passwords** (e.g. file-transfer
  passwords) and **internal + external staff names/emails**, with an explicit
  *"vendors should never contact external team members"* warning.
- **Secrets/passwords are never copied** into converted articles.
- Contact handling (names/emails vs. roles only) follows the project decision
  recorded in the session log.
- These are **living docs**, updated frequently — each converted article records
  the OneGuide "Last Updated" date; plan a periodic refresh.

## Standard OneGuide structure (what each doc contains)

1. **General Account Overview / Contacts** — internal team (processor, lead, pod,
   manager, BD/PT), external team (do-not-contact).
2. **Account Information** — account segment/tier, publication schedule, Slack
   channels, hosted URLs, account resources.
3. **Historical Context / Issue Log** — dated change decisions and past incidents.
4. **Processing Instructions per flyer type** — flyer details (when files arrive,
   publication cadence, preview date, linking doc, processing type, availability,
   Flex/OS/coupons/strategic-ops involvement), day-by-day process workflow,
   custom actions, risk items.
5. **Upload & Setup** — codesheet build steps + retailer-specific **Common Errors**.
6. **QC** — Box Draw & Box QC (include/exclude), Tag/Tag QC (field rules + category
   chart), Image QC, Spotchecks, Preview QC.
7. **Post-Processing** — Item Category QC, Item Image QC, URL/SKU QC, Final QC.
8. **Flyer Review**, **Live Dates**, **Out-of-Processing** instructions.
