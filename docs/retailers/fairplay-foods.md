## Files & schedule

- **Files received:** Monday.
- **Cadence:** Available From Wednesday, Valid From Wednesday; Available To / Valid To Tuesday.

## Upload & setup (owned by Vendor — manual upload)

- From the FTP, download the versioning spreadsheet (e.g. `Fairplay Foods Versioning Spreadsheet-2.18 AD.xlsx`).
- Create **2 pricing zones from the versioning spreadsheet: Region 1 and Region 2.**
- Add pages per the spreadsheet; add stores per the spreadsheet; draw Standard 4 thumbnails.

### Setup QC (Vendor)
- Valid dates match the PDF; no theme; available on all platforms.

## QC specifics

### Box Draw (Low; Auto-Box OFF, Box QC bot ON; no linking doc)
- **Include** special weblinks. **Exclude** coupons, packaged deals, retailer logo, sign-up page, social media.
- Each price callout is tagged individually with the item(s) it applies to. **Sub-items with different prices must be boxed separately.**

### Tag / Tag QC (Low; Auto-tag OFF; linking doc required)
- Include name, pre/postfix, valid dates, description, price, sale story, categories, disclaimer, original price. **Exclude SKU, URLs.** Brand is box-draw specific.
- Name/brand, description, price/original price — as per the flyer.
- **Pre/Postfix:** when there is **"when you buy" text, include it.**
- **Valid dates:** only if unique. **Sale story:** only if indicated on the flyer. **Categories:** to the best of your ability.

## Post-processing / Ad-Hoc QC (owned by Flex)
- Pages tab: first page(s) no categories; check # of boxes ≈ # of tags.
- **⚠️ Risk:** some items have specific valid dates — ensure tagged properly in Valid From/To.
- 4 Standard thumbnails; Geography no changes; valid dates on PDF match; vertical and horizontal previews interactive.
