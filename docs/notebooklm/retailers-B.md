# Bartell Drugs — Processing Guide

> **Source:** Bartell Drugs OneGuide (Google Doc `1qaljNVI2SzvMMTYRtPIi7NbrewXChtROrnyPI2i4ChM`), updated May 11, 2024.

| Flyer type(s) & cadence | Weekly (store 9164) |
| Processing | Auto-stack; Flex (Flyer Review); OS (Setup); no coupons; Strategic Ops (retailer data / Feedel) |

## Files & schedule

- **Files received:** Monday.
- **Publication cadence:** Available From Wednesday → Available To Saturday (2nd Sat); Valid From Sunday → Valid To Saturday.
- **Preview date:** Wednesday before go-live.
- **Available/Valid From times:** 3:00 AM.

## Upload & setup (owned by DOC)

- **Manual upload:** Fadmin "Pages" tab → Edit → upload from the corresponding FTP folder. **Auto-group; do NOT process internally.**
- **Pricing Zone:** Base.
- **Store selection:** Add All Stores.
- Attach the Linking Document to **all** vendor tasks.

### Setup QC
- Toggles: available everywhere.
- Available dates: Wednesday → 2nd Saturday. Valid dates: Sunday (after Wednesday) → Saturday (same as Available To) unless otherwise stated.
- Preview date: Wednesday prior to Available date.
- External Run Name: Page 1 callout. Theme: N/A unless otherwise stated (Black Friday, Holiday, etc.).
- Legibility heights: 40/35. Thumbnails: Standard 4.

## ⚠️ Common errors / risk items (retailer-specific)

- **Names:** only one name in the Name field. Any other names (bolded text) go in the Description in a format that keeps the item's meaning.
- **Description:** follow the PDF formatting as much as possible; exception when there is more than one brand (more than one bolded text).
- **Coupons:** do NOT list any "after coupon" prices, and do NOT list any coupon details in the sale story.

## QC specifics

### Box Draw (Low; Auto-Box ON, Box QC bot ON)
- Linking Document required (Box Draw/Box QC-specific).
- **Include:** coupons, packaged deals, retailer logo, sign-up page, social media, special weblinks.

### Tag / Tag QC (Low; Auto-tag OFF)
- Linking Document required (Tag/QC-specific).
- **Include:** name, pre/postfix, valid dates, description, price, sale story, categories, disclaimer, original price, URLs. **Exclude SKU.** No Brand field.
- Do NOT add anything to the Brand field; one brand name in Name, remainder in Description.
- Original price goes in Description; product origin must follow the original price in the Description as shown on the flyer (tag inline if inline).
- Price ranges: put the entire range in the Description, not the price fields. Do NOT include coupon info.
- **Sale Story:** DO tag "BUY 1 GET 1" and "xx% OFF" deals; do NOT tag "Hot Deal!", "NEW!", "Local!".
- **Disclaimer:** only if within the drawn box; if at the bottom of the page, don't enter it. Many herbal vitamins carry a disclaimer.
- "Select" in bolded text → move "Select" to Description; if no non-bolded text, description = "Select products".
- URLs: use the Linking Document to tag certain banners/pages as direct links.
- Every item requires a category selection.

### Image QC
- **PDFs required.** PDF image must match the item in the Name field; if only one item is named in the text, the front image must be used.

## FQC (Flyer Review type: Lite)
- Confirm dates per the PDF; add external run name (page 1 callout); Available/Valid From times set to 3 AM; confirm availability toggles.
- Thumbnails correct and include the retailer logo.
- Standard checks: all items boxed and tagged, spotchecks complete, sessions completed accurately, geography correct.
- **Post-FQC:** add preview link to the account spreadsheet and send the preview link to the retailer (Wednesday, i.e. preview date, by 12pm).

- **Files received:** Monday (retailer sends no email about file deposits).
- **Publication cadence:** Available From Tuesday → Available To Wednesday 1:59am; Valid From Wednesday → Valid To Tuesday.
- **Preview:** 1-day preview.
- **Linking Document:** N/A.

## Upload & setup (owned by Vendor)

- **Codesheet upload:** codesheet is in the FTP (.xlsx).
  - **Delete any hidden columns/rows** so the codesheet does not pull in extra unwanted information (items shown in pink were hidden and must be deleted).
  - Download the .xlsx as .csv for upload.
  - **Config name:** `bashas` (for all).
  - **PDF Base Directory:** take path from FTP.
  - **Toggles:** all except **region assignment** and **combine zones**.
- Verify in the FTP that all files for that week's path are uploaded (e.g. Oct 2 run → `/100224_Bashas`) after uploading the codesheet.

### Setup QC
- External Run Name → "Next Week's Ad". Theme → "no theme". Spotlights/Key Messages: "Our Deals. Your Savings."
- **Set trigger:** Attribute = External Display Name; Value = "Weekly Ad"; Run at = Wednesday when the flyer goes live. Leave a "trigger done" note in the comments box.
- Thumbnails: Standard 4.
- Check dates at the bottom of page 1; 1-day preview; **"Available To" is one day after "Valid To" at 1:59 AM** (2 hours after it's no longer valid).

## ⚠️ Common errors / risk items (retailer-specific)

- **No alcohol on the Dine flyer.** If any appears, call it out to the retailer.
- **Date-specific sales:** specific items in the publication carry special sale callouts (often Friday–Sunday or specific days). Ensure those items have valid dates set.

## QC specifics

### Box Draw (Low; Auto-Box ON, Box QC bot ON)
- No Linking Document.
- **Exclude:** coupons, packaged deals, retailer logo, sign-up page, social media, special weblinks.
- Box-draw all items sharing a price/description together; box entire promotional banners.

### Tag / Tag QC (Low; Auto-tag OFF)
- Linking Document required (Tag/QC-specific).
- **Include:** name, pre/postfix, valid dates, description, price, sale story, categories, disclaimer, original price, Brand. **Exclude SKU, URLs.**

### Image QC
- **PDF images preferred unless unclear.** No grey in PDF background — if grey, switch to cutout. Lifestyle backgrounds are OK.

## FQC (Flyer Review type: Lite)
- Edit Details: Valid from Wednesday 12 AM, Valid to Tuesday 11:59 PM; change Available To time to Wednesday 1:59 AM.
- Autostack spotcheck complete; standard item image QC.
- Item search — name contains "donut" → ensure valid dates set.
- Page 1 should have no page categories.
- Sales/Specials: go page-by-page and ensure products under special sales have valid dates set.
- Check previews; confirm trigger is set (from "Next Week's Ad" to "Weekly Ad" when flyer is valid).

## Out-of-processing
- Page swaps supported (see OneGuide video).

# Bath Depot — Processing Guide

> **Source:** Bath Depot OneGuide (Google Doc `1ZKUIEoqWAK7bWLqHmWm_L_63XU-9M1pyxZD6ufSkbHA`), updated Feb 3, 2026.

| Processing | Auto-stack; Flex (Flyer Review); OS (Setup); no coupons; Strategic Ops (retailer data / Feedel) |

## Files & schedule

- **Files received:** Monday, via **email in both English and French** (also on FTP with a Linking Document).
- **Publication cadence:** Available From Monday → Available To Monday; Valid From Tuesday → Valid To Tuesday (confirm dates via DOC / retailer email).
- **No preview date.**
- **Linking Document:** yes.

## Upload & setup (owned by Vendor)

- **Bilingual files:** filenames end with **AN** (English) and **FR** (French). Split multi-page PDFs into individual pages if needed (e.g. via ilovepdf.com), then manually upload.
- **Manual upload:** Pages tab → Edit → select files from FTP → group pages by page number in the filename → assign language (AN = English, FR = French) → Save & Complete. Auto-group but do NOT process internally.
- **Pricing zones:** two zones — description "EN" (English pages) and "FR" (French pages, Language: French). Confirm page order in each.
  - EN pricing zone → add **"Rest of Canada"** store group.
  - FR pricing zone → add **"Quebec"** store group.
- **Linking Document:** in FTP search ".xlsx", download it, and attach to **all** vendor tasks.
- **Edit Details:** available/valid dates per flyer; available everywhere; no theme; no preview date. Internal & External Run Name: Flyer callout.
- **Thumbnails (Standard 4):** 1065×600 – 2 pg; Stock premium – 1 pg; Storefront carousel premium – 2 pg; Storefront carousel organic – 1 pg. **Must have logo visible.**
- **Legibility heights:** 45, 35.
- Confirm all sessions have run.

## ⚠️ Common errors / risk items (retailer-specific)

- **Look for multiple products** on an item.
- **URLs differ by language:** FR page/item URLs are different from EN page/item URLs. Pull the EN URL for EN items and the FR URL for FR items from the Linking Document.
- **All items should have a link** — none should be missing a URL.
- Thumbnails must have the logo visible.

## QC specifics

### Box Draw (Low; Auto-Box ON, Box QC bot OFF)
- Linking Document required (Box Draw/Box QC-specific).
- **Include:** retailer logo, sign-up page, social media, special weblinks, banners with sales callouts. **Exclude coupons, packaged deals.**
- Follow the link sheet; items are listed top-of-page to bottom-of-page.

### Tag / Tag QC (Low; Auto-tag OFF)
- Linking Document required (Tag/QC-specific).
- **Include:** name, description, SKU, price, sale story, categories, disclaimer, original price, URLs, Brand. **Exclude pre/postfix, valid dates.**
- Add the website on the front page; add links to bottom categories and the last page.

### Image QC
- Standard Image QC; **pick clean PDFs whenever available.** If no clean PDF images are available, may need to grab JPGs from the retailer's website and upload.

## FQC (Flyer Review type: Lite)
- **Pre-FQC (Links QC):** Overview → Information/Reports → Items without a URL; resolve every missing URL from the Linking Document (mind EN vs FR URLs) until 0 remain.
- Mark Autostack complete; dates per retailer email; hidden on hosted but available everywhere; no preview date; no theme.
- Page categories: remove from page 1, apply most appropriate page category.
- Check merged pages; open item view for both pricing zones; verify vertical preview is interactive.
- Sessions run & FSAs generated; geography green (no week-over-week changes).
- Send preview link no later than 1 business day before go-live (no hosted).

- **When files arrive / cadence:** Ad Hoc.

- **Involvement:** Flex (Processing Support + Flyer Review); no coupons; no
  Strategic Ops / Feedel.

1. **Pages tab → Edit →** select all pages from the SFTP menu → Confirm & Upload.

4. **Create Base pricing zone**, select all applicable pages, Save & Confirm, add
   all stores.

- Confirm all pages uploaded (Pricing Zone → Items View). **Risk:** if uploading
  from SFTP, confirm no SFTP pages were left un-uploaded.

- **Tag / Tag QC:** Low; Auto-tag **on**. **Include:** name, pre/postfix, valid
  dates, description, price, sale story, categories, disclaimer, original price,
  URLs. **Exclude:** SKU.
- **Image QC:** PDF preferred if clean; otherwise cutouts accepted.

## Final QC / review

- Confirm dates vs. PDF; availability toggles correct; thumbnails include the
  retailer logo; all items boxed/tagged; spotchecks on 20% of pricing zones;
  previews published & clickable; geography correct. **Flyer Review type: Lite.**

## ⚠️ Common errors / risk items (retailer-specific)

- **Look for multiple products** on an item.
- **SKU sourcing:** if a SKU isn't found on the website, fall back to (1) product name in the Name field, (2) the **page title** as the name, or (3) the same name for multiple products on the page.
- Not all products will have a link; if no linking doc is attached, proceed with tagging without linking.

## QC specifics

### Box Draw (Low; Auto-Box ON, Box QC bot ON)
- No linking document for Box.
- **Include:** retailer logo, sign-up page, social media, special weblinks. **Exclude:** coupons, packaged deals.
- Draw clean boxes around items and their prices. **Text box rules:** ONE text box when the item is separated from its price/description; TWO text boxes when an item has more than one text callout (linked by a letter, e.g. "C") — box both.
- Box each item separately.

### Tag / Tag QC (Low; Auto-tag OFF; PDF Image Auto Selection ON)
- Linking Document required (Tag/QC-specific).
- **Include:** name, description, SKU, price, sale story, categories, disclaimer, original price, URLs, Brand. **Exclude:** pre/postfix, valid dates.
- **Name/Brand:** search the item's SKU on the banner website; if found, copy the name from its webpage. Always include the SKU.
- Sale story: tag sale callouts per the item (e.g. "Save 25%", "50% off", "$50 off", "Save $1500").
- Enter Current Price; include Original Price where applicable (some products have none).

### Image QC
- Prioritize PDF images unless not clean (shadows, black backgrounds). If only a partial image is shown, use a cutout.

## Post-processing / FQC (Flyer Review type: Lite; owned by DOC)
- **URL/Links QC:** each banner has a standard set of link callouts (Shop Safely In Store, Book Appointment, Financing, Curbside Pickup, Free Shipping, social media, etc.) — full URL list is in the OneGuide.
- **FQC:** Ledge heights 60/40; logos boxed and linked; bottom callouts (shop online, curbside, etc.) boxed and linked; each SKU boxed and tagged.
- If a URL document was shared, check Items without URL and add where possible (OS uses the SKU on the website to find the product name).
- Page categories: one per page, max 3. Verify session links; check horizontal and vertical previews.

## ⚠️ Common errors / risk items
- **Pricing-zone page order (top risk):** two versions exist — **Version A** and **Version B**, distinguished by an A or B in the page name. A Version A page must **never** be in a Version B zone or vice versa.
- **Alternate pricing per KG goes in the description**, not the postfix. Example — Name: New York Strip Loin Roast; Description: "Canadian AA or Better Grades of Beef / 19.80/kg"; Current Price $8.98; Postfix "lb".
- Box the **text rather than the image** on pages with multiple overlapping products.

## QC specifics

### Box Draw (Low; Auto-Box ON, Box QC bot ON)
- **Exclude:** coupons, packaged deals, retailer logo, social media.
- **Include:** sign-up page, special weblinks.
- Box all items with prices, using text boxes when needed. Box "More REWARDS" pages → name "More REWARDS", link `buy-low.com/morerewards`.
- **Risk:** watch for **date-specific items** (special valid-date callouts).

### Tag / Tag QC (Low; Auto-tag ON; PDF image auto-select ON)
- **Include:** name, pre/postfix, valid dates, description, SKU, price, sale story, categories, disclaimer, original price. Brand used for box/tag. **Exclude URLs.**

- Watch date-specific items — add the specific dates to items with a callout.

### Image QC
- Use a clean PDF image when available (almost all items have one); do not use if the product is cut off. Otherwise use the cutout.
