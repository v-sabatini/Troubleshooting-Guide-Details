## Files & schedule

- **Files received:** ad-hoc — provided by **BD**.
- **Publication cadence:** ad-hoc.
- **Linking document:** Yes.

## Upload & setup (owned by FLEX)

- Pages may need to be added to SFTP by the processor. **Manual upload:** Pages Tab → Edit → upload BD-provided pages via manual upload → Confirm & Upload → Auto-Group or add page numbers → set correct language → Save & Confirm (**do NOT process internally**).
- **Pricing zone:** create **Base**, select all pages, Save & Confirm, add all stores.
- Setup QC: confirm all pages uploaded; confirm flyer dates (provided via email); thumbnails Standard 4; preview dates set; **mass-attach the URL document to all processing steps (Box, Tag, Tag QC)**.

## QC specifics

- **Box Draw (Low; Auto-Box ON, Box QC bot OFF; linking doc used for both Box & Tag):** exclude coupons, packaged deals, retailer logo, sign-up page, social media, special weblinks.
- **Tag / Tag QC (Low; Auto-tag ON; linking doc used for both Box & Tag):** include brand, name, pre/postfix, valid dates, description, price, sale story, categories, disclaimer, original price, **URLs**. **Exclude SKU.**
- **Image QC:** PDF preferred if clean; cutouts otherwise.

## ⚠️ Common errors / risk items

- **All items must link to `https://www.thebeerstore.com`** (verified during pre-FQC).

## FQC / flyer review

- Pre-FQC (FLEX): dates vs PDF; availability toggles; thumbnails include retailer logo; all items link to thebeerstore.com; all items boxed/tagged; spotchecks (20%); previews clickable; sessions complete; geography correct.
- **Flyer Review type: Lite.**
