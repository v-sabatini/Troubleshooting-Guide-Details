## Files & schedule

- **Files received:** Monday. Codesheets labeled `WK__ RCWC EF FINAL CODES`; download and upload to the LCL Flex Upload folder, and update the Flex Tracker.
- **Cadence:** Available From Wednesday, Valid From Thursday; Available To / Valid To Wednesday (1-day consumer preview). Set a preview date for the Monday before live (for OS to prioritize).

## Upload & setup (manual)

- **Only refer to the EF tab** for page numbers, store changes, URLs.
- Select all Extra Foods files under the correct week; upload as English pages; number per codesheet — **usually 1 page + a HOTM flap page.** Check the Merchant FTP that all pages pulled in.
- Pricing zone: **Base** — usually 1 PZ, sometimes 2. Add stores: EF store set → Add all (2 stores as of Sept 2024). If a 2nd PZ, adjust stores per codesheet.
- Edit Details: external run name format `Weekly flyer Valid Thursday, July 14 - Wednesday, July 20`; no theme.

## QC specifics

### Box Draw (Low; Auto-Box ON, Box QC bot ON; linking doc required)
- **Include** coupons, packaged deals. **Exclude** retailer logo, sign-up page, social media, special weblinks.
- Box only around the item where there's a unique price. **Box banners linking to nofrills.ca; do NOT box/tag Facebook, Twitter, etc.**

### Tag / Tag QC (Medium; Auto-tag OFF; linking doc required)
- Include name, pre/postfix, valid dates, description, SKU, price, sale story, categories, disclaimer, original price. **Exclude URLs.** Brand is box-draw specific.
- **Name:** ALL CAPS, `Brand Product Name, Quantity` (always a comma before quantity). **Tag all info in FRENCH AND ENGLISH, separated by "/".** Product name is bold in the flyer.
- **Description:** plain (non-bold) text; capitalize first letter; metrics like `2.56/kg`; "Product of…", "No. 1 grade", "frozen", "selected varieties".
- **SKU:** only when in flyer. Multibuy items need Postfix Text and Postfix Amount.
- **Valid dates:** apply item date overrides only when a promo sales story on the item calls for it.
- **PC Optimum:** tag as normal item; sale story includes the PC Optimum points offer.
- **Images — Rule 1:** cleanest PDF (white/clear background); no shadows/lifestyle → don't use PDF. **Rule 2:** PDF for meat/seafood/cheese only if packaged; if not packaged, use cutout.
- **Page-level categories** during box draw for all pages **except front cover** (Deli & Ready Meals, Bakery, Meat & Seafood, Dairy & Eggs, Drinks, Baby Needs, Household Supplies, Beauty & Skincare, Medicine & Health, Frozen, Produce).

### Post-processing (owned by DOC)
- Item Category QC, Item Image QC, URL/Links QC, SKU QC, Ad-Hoc QC.

## Pre-Final QC / FQC (owned by DOC)
- Storefront: merge flap page to the right; if two flap pages, merge them; if one, merge with front/cover P01.
- Ledge heights 40/30.
- **⚠️ Image QC — MEAT & SEAFOOD:** do NOT select PDF images of raw meat/seafood; OK if in a package with a label; otherwise use cutout.
- Thumbnails Standard 4, start where the logo is; **do NOT include flap pages** even if merged to cover.
- **⚠️ Risk:** number of pages varies across zones — modify thumbnail start position accordingly.
- Item view: all items boxed. Check URLs from the codesheet; box/tag links written on PDFs (e.g. PC Children's Charity box). Known links: PC Optimum (pcoptimum.ca), Extra Foods (extrafoods.ca).
- Page categories 1–2 per page except page 1.
- Item searches: categories blank; SKU blank; URL blank where SKU present (fill article number if URL present but article number 1 blank).
- FQC: Available Wed–Wed (1-day preview), Valid Thu–Wed, available everywhere, external run name set. Log flyer ID in the LCL Tracker by 2:30 Monday.
