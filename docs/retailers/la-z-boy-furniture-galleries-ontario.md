## Files & schedule

- **Files arrive:** ad-hoc. **Flyer assets often sent late or without email confirmation** — expect (1) a custom tile JPEG and (2) the flyer PDF.

## Upload & setup (owned by DOC)

- 1 PZ = Base; add all stores **unless told otherwise** (e.g. a closing/opening sale may be a single store).
- Flyer Details: check avail + valid dates (**should be the same**); Internal Run name = title of flyer; available everywhere; no theme.
- **Custom tile:** check the FTP for the `.jpg` custom tile (FAdmin auto-checks jpg files but still download it). In the QC Thumbnail interface, for **Storefront Premium** and **Storefront Carousel Premium**: Choose File → upload the .jpg → **Override Thumbnail** → select the "Base" PZ → OK. Repeat for both.

### Setup QC
- Standard Setup QC.

## QC specifics

- **Box Draw (Low; Auto-Box ON, Box QC bot ON):** no linking doc. **Include retailer logo and sign-up page**; exclude coupons, packaged deals, social media, special weblinks. Box "yes" items and any call-outs.
- **Tag / Tag QC (Low; Auto-tag OFF, PDF image auto-selection ON):** no linking doc, **no brand**. **Include** name, description, price, sale story, categories, original price. **Exclude** pre/postfix, valid dates, SKU, disclaimer, URLs. Use clean PDF image where possible; cutout when not available.
- **Spotcheck risk:** OS often puts the furniture piece name as the Brand — **Brand should be La-Z-Boy**.
- **Image QC:** PDF preferred (Ontario only); otherwise item cutout.

## Final QC / go-live notes (owned by DOC)

- Pre-Final QC: sessions/vendors complete; thumbnails done (Standard 4, custom tile applied); geography matches previous week.
- **Flyer Review type: Lite** (owned by Flex).
