## Files & schedule

- **Files received:** weekly, via SFTP.
- **Publication:** Available/Valid From Thursday → Wednesday (match PDF dates); preview N/A; linking doc N/A.

## Upload & setup (owned by Flex)

- Manually upload all pages → Auto group → **EN only**.
- **Pricing zones depend on the file dropped in SFTP:**
  - If the file name reads **`D_BR_AH_MO`** → create **1 pricing zone named `base`**, assign all 4 stores.
  - If there are 2 PDFs (**`D_BR_AH`** and **`Mokena`**) → create **2 zones**: `Mokena` (Mokena store only) and `Darien` (remaining 3 stores).
- Thumbnails standard 4; Available/Valid From Thursday, To Wednesday (match PDF); all platforms; **grocery → theme always NO THEME**.

### ⚠️ Common errors / risk items (retailer-specific)

- **Zone/store assignment is the key risk at FQC:** confirm the `Darien` and `Mokena` zones exist and **each has exactly 2 stores.** If a zone has more or fewer than 2 stores, flag for correction.
- Grocery — theme must always be NO THEME.
- Valid dates must come from the PDF; available from is 1 day prior to the PDF date.

## QC specifics

- **Box Draw — Low complexity. Auto-Box OFF, Box QC bot OFF. No linking doc.** Exclude coupons, packaged deals, retailer logo, sign-up page, social media, special weblinks. Box any item with a price or sale story.
- **Tag / Tag QC — Low. Auto-tag OFF. No linking doc. No brand. Exclude valid dates.** Include name, pre/postfix, description, SKU, price, sale story, categories, disclaimer, original price, URLs.

## FQC / go-live (owned by Vendor)

- Confirm all vendor tasks complete; verify `Darien`/`Mokena` zones each have exactly 2 stores (flag otherwise).
- Geography consistent week over week; check vertical/horizontal previews; dates match PDF (available 1 day prior).
- **Flyer Review type: Lite** — no special risk items.
