## Files & schedule

- **Files received:** Monday (often late — 3–4 days before go-live).
- **Available From:** Wednesday · **Valid From:** Thursday · **Available To:** Monday · **Valid To:** Tuesday (1 day preview).
- **Workflow:** Upload & Setup (Vendor, 5 days out) → Image QC (FLEX, 2 days out) → FQC (DOC, 1 day out).
- Only flyer pages uploaded during setup; **all inserts uploaded during FQC**.

## Upload & setup (owned by FLEX)

Manual upload. Two pricing zones per banner: **(1) ENG, (2) BIL** — assign **all stores to each** pricing zone.
- Select the correct banner's files (TRU / BRU / r+s), and both BIL (bilingual) and ENG (English) files.
- **Change language toggle to French for all BIL files**, save, confirm French applied, then Auto-Group → Save & Complete.
- Ensure all ENG files → ENG zone, all BIL files → BIL zone.
- If the retailer requests a page only for certain regions, set pricing zones & assign stores accordingly.
- Typical note: EN usually has one more page than FR.

## ⚠️ Common errors / risk items (retailer-specific)

- Carefully check analytics categories are tagged correctly per the **category chart** (categories differ for TRU vs BRU — only choose from the correct flyer type).
- Highlights: tag only if item carries the **"Only at Toys R Us/Babies R Us"** banner ("R" Exclusives star).
- **No general sale stories** for items that have an individual name and SKU.
- Ensure **all disclaimers** are added (common in these flyers).
- **Product links:** must be the direct product-page URL, not a search page; watch **EN vs FR** link mismatches (EN pages must have EN links). SKUs starting with 0 must drop the leading 0 when searching the website.

## QC specifics

### Box Draw (Low complexity; Auto-Box ON, Box QC bot OFF)
- No linking document required for box draw.
- **Include:** coupons, packaged deals, sign-up page, social media, special weblinks. **Exclude** retailer logo.
- If one sale story + one price but multiple items with different SKUs → box separately.
- Each item with matching price and SKU gets its own box (image + matching text).

### Tag / Tag QC (Medium complexity; Auto-tag OFF; PDF Image Auto Selection ON)
- Requires Tag/QC-specific linking document.
- **Brand:** enter if applicable (often first word of name, or in the general sale story, or a logo beside item).
- **Name:** as in flyer, first letter of significant words capitalized; include the brand if part of the name.
- **Description:** descriptive info from the flyer only (not the website); do NOT put NG Code or SKU in description... actually SKU goes in **both** Description and SKU fields.
- **URLs:** enter a URL for every item (EN and FR) from toysrus.ca / babiesrus.ca / roomsandspaces.ca; SKUs starting with 0 drop the 0 when searching; use the first matching item; leave blank if not found.
- **Price:** prefix (usually "NOW"; include quantity for multi-buy e.g. "2"), current price (bold, after "NOW"), original price (after "REG." or the "after event" price), postfix if applicable (don't include "Reg").
- **Valid dates:** common — front cover and throughout as "3 DAYS ONLY!" (yellow banner). Items marked "Coming [date]" get that valid start date.
- **Page categories:** per the category chart; choose when the majority of items match; different charts for TRU vs BRU.

### Image QC (owned by FLEX; DOC to review)
- Prioritize clear PDF images as much as possible; most products should have PDF images.
- Acceptable: white background, lifestyle background (if product aligns), slight grayish shadow, opposite direction (if picture aligns).
- **Not acceptable:** black background / obvious black shadow → use cutout. If no PDF matches, use the cutout.

### Post-processing (Links / Item Category / Page Category QC)
- **Links QC:** search URL is blank + Item Type Item; find URL on retailer site; verify EN/FR language alignment (search URL contains /en/ with Language French → swap to /fr/, and vice versa); links must go to the product page, not a search page.
- **Item Category QC:** categories should match the website category (Overview → ad hoc processing → QC categories). Use website product listing; if not found, keyword-search a similar product. Insert links may have no category. Mark QC complete; Unreviewed Items search should return nothing.
- **Page Category QC:** one category per page except first page/inserts.

## FQC / out-of-processing
- **Flyer Review type: Lite** (owned by FLEX).
- File Flex ticket after vendor tasks. 45/35 leg heights; four standard thumbnails; no theme; external run name blank.
- Inserts added at end of each flyer during FQC (weekly inserts + yearly inserts, tagged with provided links; toggle French per file names).
- Preview links shared before go-live; corrections and page swaps handled post-live (page swaps prefixed "REV"; OPTICS ticket with version/position/changes/run links).
