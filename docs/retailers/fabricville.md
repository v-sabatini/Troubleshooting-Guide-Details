## Files & schedule

- **Files received:** Monday, via WeTransfer link in the email from the Fabricville team.
- **Cadence:** Available From Monday, Valid From Tuesday; Available To Monday, Valid To Tuesday.

## Upload & setup (owned by Flex — bilingual EN/FR)

- Download files from the WeTransfer email and upload to the Fabricville FTP; wait for the sync to fadmin before the manual upload.
- **Manual page upload:** Pages → Edit; select both English and French pages from the FTP (typically in separate folders).
- **Set French pages' language to French,** then Save (not Save & Complete). **⚠️ Often one French page reverts to English — re-check all FR pages are toggled to French.** Then **Auto-Group** to number pages; confirm equal EN and FR counts. Save & Complete.
- **Pricing zones:** create one PZ named **English** (all EN pages), one named **French** (all FR pages, **toggle language to French or FR pages won't appear**). Save & Done.
- **Stores:** add all stores to both zones (0/0 → Add All).
- **Linking document:** mass-attach both EN and FR docs to all vendor tasks, then delete the mismatched-language doc from each task (EN task keeps EN doc, etc.).

### Setup QC (Flex)
- Confirm page counts per PZ; Geography tab should be green.

## ⚠️ Risk item — content policy
When files arrive, confirm the flyer meets content policy: **enough images matching offers, and enough offers per page.**

## QC specifics

### Box Draw (Low; Auto-Box OFF, Box QC bot ON; linking doc required)
- **Exclude** coupons, packaged deals, retailer logo, sign-up page, social media, special weblinks.
- Items stacked together → **box each separately** (do not group).
- One item with different styles/types in a block (e.g. 4 dresses, one price) → **one box for the whole block.**
- **⚠️ Overarching offers:** multiple fabrics/prices under one offer (e.g. "Home décor fabrics up to 50% off") → **one box per offer.** If unsure, use the linking document; one row per page = one box.

### Tag / Tag QC (Low; Auto-tag OFF; PDF image auto-selection ON; linking doc required)
- Include name, pre/postfix, valid dates, price, sale story, categories, disclaimer, original price, URLs. **Exclude description, SKU.** Brand is box-draw specific.
- **Name:** bigger/bold font; copy exactly as shown (capitalization included).
- **No SKU** for any item.
- **Valid dates:** always from the flyer; if an item's date differs from the flyer, use the item's exact date.
- Complex cases: items under a common header, or 2 items grouped into one — tag per the linking-document examples.

### Image QC
- Standard.

## FQC (owned by DOC)
- **Item-count check:** the run's item count should equal the linking-doc row count minus 1 (header). Mismatch → rebox/tag per the linking document.
- Verify boxes/pages drawn correctly per PZ; complete Standard 4 thumbnails; Geography tab unchanged week over week unless requested; mark items In-Store Only; check vertical preview.

- **Type: Lite.**
