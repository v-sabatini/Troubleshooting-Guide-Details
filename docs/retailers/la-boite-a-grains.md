## Files & schedule

- **Files arrive:** Friday.
- **Cadence:** Available/Valid From Wednesday → Available/Valid To Tuesday (monthly flyer).
- **Two upload patterns:** (1) once a month a net-new **Monthly** flyer; (2) weekly **page swaps** — a new produce page swapped into the existing run. Always confirm which you're being asked to do.

## Upload & setup (owned by Vendor)

- **Manual upload:** client sends the PDF to SFTP; linking doc usually arrives as an email attachment. Pages → Edit → upload all individual page files from the **lowercase** folder — upload them **twice**. Auto-group; set all pages to French; Save and Complete.
- **Flyer creation:** make a French PZ (description "FR", pages in correct order); make a second PZ "ENG" with the same French pages, check **"Cross language?"** and change language to English. Save and Complete.
- **UTM code:** taken from the linking doc; updated code = the new flyer month in French (e.g. OCTOBRE). Overview → Ad Hoc Processing → Manage Tracking Codes → edit → Update Code → **Apply all Tracking Codes**.

### Setup QC
- Add all stores to both zones; vendors assigned; linking doc attached to vendor tasks.
- Edit Details: dates correct (confirm via client email), available everywhere, no external run name, **No Theme**.
- Legibility heights: **Scan 50, Read 40**. Thumbnails Standard 4.

## QC specifics

- **Box Draw (Low; Auto-Box ON, Box QC bot OFF):** **Exclude** coupons, packaged deals, retailer logo, sign-up page, social media. **Include special weblinks.** Box each item with a price; items with **two prices are boxed separately**; box each recipe that includes a link URL.
- **Tag / Tag QC (Low; Auto-tag OFF, PDF image auto-selection ON):** **Include** brand, name, pre/postfix, valid dates, description, SKU, price, sale story, categories, disclaimer, original price, URLs. **Use cutout images.**

## Final QC / go-live notes (owned by Vendor)

- Geography green — **no stores/FSAs added or removed**.
- Both PZs: item view (no missed boxing), vertical + full-screen previews, all stores added, one PZ English + one French, pages ordered correctly.
- Items Without a URL → add links from the linking doc where possible.
- Ignore the "Not all categories that are used in pricing zones have thumbnails" warning.
- **Flyer Review type: Lite.**

## Out-of-processing: weekly page swap

- Monthly run is refreshed weekly by replacing the **produce page** (usually 3rd position). Page often arrives Tuesday, needs to be live **Wednesday**.
- Because of the turnaround, **upload, box and tag the page yourself** (twice — ENG and FR) rather than leaving steps for OS. Set a trigger via Pages → Layout: put the page into position 3 in both PZs, **run as trigger for Wednesday 12am**.
- File an Optics ticket for processor/lead review once the trigger is set.
