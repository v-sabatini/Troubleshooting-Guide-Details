## Files & schedule

- **When files arrive:** Monday (files + Posting Document dropped to FTP for all SpartanNash banners). Available/Valid From Sunday → To Saturday.

## Upload & setup (owned by Vendor)

- Download the **Posting Document** to confirm page order; upload pages from FTP and order per that document.
- Pricing Zone: **Base** — Add all **10 stores** (1570, 1577, 1591, 1573, 1576, 1571, 1574, 1575, 1903, 1525).
- Confirm first-page valid dates are Sunday–Saturday. Edit Details: Available/Valid From/To Sunday–Saturday; available everywhere; no theme. Thumbnails Standard 4.
- **Clear the FTP files (including the Posting Document) after upload.**

### ⚠️ Common errors / risk items (retailer-specific)

- **Confirm all pages uploaded** (Pricing Zone → Items View). **RISK — if uploading from SFTP, check no pages remain un-uploaded in the SFTP.**
- **Free Item Download items** must be boxed.
- **Multiple prices in one ad block:** do **NOT** put the second price in the Original Price field — put the **Sale Price in Current Price** and the **Coupon/Extra Savings offer in Sale Story**.
- **2-Day / 3-Day sale banners:** tag all items in the banner with the appropriate unique valid dates.
- **Ignore the warnings in the FQC checklist** and proceed with FQC.

## QC specifics

- **Box Draw (Low; Auto-Box ON, Box QC bot OFF).** No linking doc. Box all items with prices (use text boxes when needed). **Include** coupons, special weblinks. **Exclude** packaged deals, retailer logo, sign-up page, social media.
- **Tag / Tag QC (Low; Auto-tag OFF).** Include name (all items in the ad block), pre/postfix, valid dates, description, price, sale story, categories, disclaimer, original price. **Exclude SKU and URLs.** Brand used for both Box/Tag. Prefix selected from the approved drop-down.
  - **Item categories:** required on every item. **Baby → "Health and Beauty"; Pet → "Grocery".**
- **Image QC:** **not using PDF images — use item cutouts.**

## Final QC / go-live (owned by Vendor)

- Complete any remaining spot checks; check for narrow pages in Storefront Spotcheck per pricing zone and merge to the next page; mark Autostack Spotcheck complete.
- Image QC not required (no client preferences given). Review each page for special-day sales (e.g. 3-Day) and apply correct unique valid dates.
- FQC checklist: spot checks, Thumbnail QC (Standard 4), legibility heights, geography vs. prior weeks, page order/region, toggles, all items tagged, dates match the PDF, no "real" overview warnings.
- **Flyer Review type: Lite** (owned by FLEX) — checks dates, sessions complete, previews correct, tagging accurate, geography, availability toggles.
