## Files & schedule

- **Files received:** Friday afternoon; upload Friday. Flag the contact if files aren't in by 2 PM. If received Monday (rare), file an urgent processing ticket for FQC Tuesday.
- **Cadence:** Available From Wednesday, Valid From Thursday; Available To / Valid To Tuesday (1-day consumer preview).

## Upload & setup (owned by Vendor — manual)

- Pages → Edit → select all pages (usually 7–12). **Auto-Group** → Save → Save & Complete.
- Flyer Creation → create **1 zone named Base**; verify pages → Save & Complete.
- Pricing Zone tab: generally **Add All stores.** **⚠️ Sometimes the contact requests some stores get a different version — make two zones and split stores per the email (rare).**
- Download and attach the **URLs document** to all vendor tasks.

### Setup QC (Vendor)
- Geography: same week over week — should read **"No Stores or FSAs/zips were added or removed!"** (refer to the contact's email/DOC notes for rare changes).
- Vendors: URL document attached. Sessions ran correctly (**Page Stitching and PDF Image Auto Selection yellow is fine**).
- Edit Details: 1-day consumer preview (Available Wednesday, Valid Thursday), available everywhere (no toggles), no external run name, no theme.
- Thumbnails Standard 4.

## QC specifics

### Box Draw (Low; Auto-Box ON, Box QC bot ON; linking doc required)
- **Include** packaged deals, retailer logo, sign-up page, special weblinks. **Exclude** coupons, social media.
- Box food items; **box any menus that have prices.**

### Tag / Tag QC (Low; Auto-tag ON; linking doc required)
- Include name, pre/postfix, valid dates, description, price, sale story, categories, disclaimer, original price, URLs. **Exclude SKU.** Brand is box-draw specific.
- **Name/Brand:** include brand in the Name field if shown on the page. **Description:** all descriptive text.
- **⚠️ Postfix:** tag only the **`/lb`** info — **ignore `kg`** (the per-kg figure is not tagged; it belongs in the description context).
- **Valid dates:** only if different from the flyer run.
- **⚠️ Do not box items that only have a per-kg figure and no sale price** (e.g. a vinaigrette listed at "8.80/kg") — put the text in the Description; don't box separately.

### Image QC
- **Cutouts only:** Generate all, then check off all as reviewed.

## FQC (owned by DOC — done ~noon/1pm the day before live)
- Geography: all stores assigned, same week over week — "No Stores or FSAs/zips were added or removed!". Vendor tasks complete. Sessions green except PDF Image Auto Selection (yellow); verify links (redo if links change later).
- **Item view:** confirm all items boxed; missing → Pages → Box QC → box/tag yourself.
- **⚠️ Menu items with prices** (usually pages 5–8, 2–3/week) must be boxed/tagged: Name = the menu name (e.g. "Mother's Day Menu"); Description = dishes offered, reheat time, ordering/pickup dates; include the link. Recipes don't need tagging **unless there's a sales callout (a price).**
- Pages: all items boxed/tagged/QC'd (Vendor QC yellow numbers clear by opening the page and saving items until green).
- Categories: no category for page 1; best judgement for others; pages without items need none; Menu-item pages can be tagged **Deli.**
- URLs: use the linking doc (usually 4–5 links, often applied to a whole page). **⚠️ CONFIRM URLs are correct during FQC.**
- Legibility heights **Scan 45 / Read 35.** Item image QC = cutouts only. Standard 4 thumbnails.
- Ignore the "Not all categories that are used in pricing zones have thumbnails" warning.

## Flyer Review
- **Type: Lite.**

## Out-of-processing
- **Page swaps** are fairly common (watch for the contact's email) — generally low-context and actionable by Flex; make a FAB ticket as needed.
