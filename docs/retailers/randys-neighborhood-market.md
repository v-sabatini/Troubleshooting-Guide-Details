## ⚠️ Risk item — file-name dates
**Dates in the file names will be 3–4 days earlier than the actual date on the flyer run shell and on the PDF itself.** This is a quirk of the retailer's production process and can be ignored (called out in both Setup and FQC).

## Upload & setup (owned by Vendor)
1. Upload all pages manually.
2. Create **2 pricing zones: "DEW" and "OSA"**.
3. Add all pages with "DEW" in the filename to DEW, all "OSA" to OSA — in page position per the page-number in the filename.
4. Add the **Dewitt store to the DEW zone** and the **Osage store to the OSA zone**. The Dyersville store is intentionally unassigned.
- Setup QC: confirm all checklist items correct.

## QC specifics
- **Box Draw (Low; Auto-Box OFF, Box QC bot OFF):** exclude coupons, packaged deals, logo, sign-up, social, special weblinks. Box all items with a price; box reward trade-in items and Buy-X-Get-X-free promos.
- **Tag / Tag QC (Low; Auto-tag OFF):** include Brand, Name, Pre/Postfix, Description, SKU, Price, Sale Story, Categories, Disclaimer, Original Price, URLs. Exclude Valid Dates.
