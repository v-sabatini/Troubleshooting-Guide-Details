## Files & schedule

- **Files arrive:** ad-hoc.
- **Cadence:** Available From ~2 days before the 1st or 15th → Available To 14th or last day of the month; Valid From 1st/15th → Valid To last day of month. Pages may need to be added to SFTP by processor if the client emails files.

## Upload & setup (owned by Vendor)

- **Manual upload:** Pages → Edit → select all from SFTP → Confirm & Upload. Auto-Group; language **French ONLY**. Save (confirm pages stay French); Save & Confirm — **do NOT process internally**.
- **Pricing zone:** create Base PZ, select French (all pages show). Save & Confirm. Add all stores.
- Attach the linking document to the flyer run.

### Setup QC
- Confirm all pages uploaded (PZ → Items View); confirm flyer dates (usually first/last page); thumbnails Standard 4.

## ⚠️ Common errors / risk items

- **Brand-blank check (pre-FQC):** Item search Brand → IS → (leave blank). This should return **no results**. If there are, tag brands based on the flyer PDF; if a brand can't be determined, leave it blank.

## QC specifics

- **Box Draw (Low; Auto-Box ON, Box QC bot OFF):** no linking doc. **Exclude** coupons, packaged deals, retailer logo, sign-up page, social media, special weblinks. Include **all products**; exclude retailer logo & social media.
- **Tag / Tag QC (Medium; Auto-tag ON):** linking doc required (tag-specific). **Include** brand, name, pre/postfix, valid dates, description, price, categories, disclaimer, original price. **Exclude** SKU, URLs. Sale Story **only if "ECONOMISEZ" is visible** for the item.
  - Always include brands in **both** the Brand field **and** the Name field. Always tag the description. Tag original price (REG) if on the PDF. Reference the linking doc to tag brands/names correctly.

## Final QC / go-live notes (owned by DOC)

- Confirm dates (per PDF), availability toggles, thumbnails include the retailer logo.
- Standard checks: all items boxed/tagged, spotchecks (20% of PZs), previews published + clickable (**vertical preview will not work**), sessions complete, geography correct.
- Repeat the **Brand → IS → blank** search (should return zero results).
- **Flyer Review type: Simple** (owned by DOL).
