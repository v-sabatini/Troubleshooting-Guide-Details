## Files & schedule
- **Files arrive:** Monday (retailer drops files + a **Posting Document** to the FTP; sends email when dropped).
- **Cadence:** Available/Valid From Sunday → Available/Valid To Saturday.
- Workflow: Upload/Setup (Flex, 5 days out) → FQC (Vendor, 1 day out).

## Upload & setup (owned by Vendor)
- Pages may need to be added to the SFTP by the processor if the client sends files over email.
- Download the Posting Document to confirm page order; upload pages from FTP and order them per the Posting Document.
- Pricing Zones: **Base**, add all stores (**1 store — 3077**).
- Wait for sessions; ensure vendor tasks are ready/active.
- Review first page — **valid dates Sunday–Saturday.**
- Edit Details: Available/Valid From/To Sunday–Saturday; **Hidden in Hosted**; no theme; **set preview day to Thursday** so FQC is ready Friday.
- Thumbnails (Standard 4); **leg heights 45/35**; Setup QC.
- Clear the FTP files (including the Posting Document) when done.

### Setup QC (owned by Vendor)
- Confirm all pages uploaded (PZ tab → Items View; **RISK:** if uploading from SFTP, confirm no un-uploaded pages).
- Confirm flyer dates (usually first or last page); 4 standard thumbnails; preview dates set; complete Setup QC.
- **Add to the VAST Tracker for Vendors to complete FQC.**

## ⚠️ Common errors / risk items
- **We are currently NOT using PDF images — use item cutouts ONLY.**
- **Multiple prices:** do NOT put the second price in the Original Price field. Enter the "Sale Price" in Current Price and the "Coupon/Extra Savings" offer in Sale Story.
- **2-Day / 3-Day sale banners:** tag all applicable items with the unique valid dates.
- FQC checklist warnings can be ignored.

## QC specifics
- **Box Draw (Low; Auto-Box ON, Box QC bot OFF):** **Include** coupons and packaged deals; **exclude** retailer logo, sign-up page, social media, special weblinks. Box all items with prices or sale stories (use text boxes when necessary); box coupons but not other price text on prescription items.
- **Tag / Tag QC (Low; Auto-tag OFF):** Brand used for both box/tag. Include name (all items in the ad block), pre/postfix, valid dates, description, price, sale story, categories, disclaimer, original price; **exclude SKU and URLs.**
  - Prefix from the approved dropdown; everything else as in flyer.
  - Sale Story: Extra Savings / MFR Rebate / Digital Coupon offers — tag everything in the blue box.
  - **Categories:** every item needs one; **Baby products → "Health and Beauty"; Pet products → "Grocery".**
- **Image QC:** cutouts only (no PDF images).
- **Spotchecks:** standard pricing spotchecks.

## Post-processing / FQC (owned by Flex)
- Complete any leftover spot checks; check for narrow pages in "Storefront Spotcheck" per PZ and merge to next page if any; mark Autostack Spotcheck complete.
- Image QC not required (no client Image QC preferences yet); use cutouts.
- Review each page for special days (3-Day Sales) and apply unique valid dates.
- FQC checklist (ignore warnings): spot checks; thumbnail QC (Standard 4); legibility heights; geography matches previous weeks; pages in correct order/region; toggles correct; all items tagged; dates match PDF; no 'real' warnings.

- **Type: Lite.** Owned by Flex.
