## Files & schedule

- **Files received:** Monday, dropped to FTP with a Posting Document (email sent when files drop). Pages may need to be added to the SFTP by the processor if the client sends files by email.
- **Cadence:** Available From Sunday, Valid From Sunday; Available To / Valid To Saturday (1-day preview). Set a preview for the Thursday before go-live.

## Upload & setup (owned by Vendor)

- Download the **3 Posting Documents** to confirm page order; upload pages from FTP and order per the Posting Document. **Each posting document is a pricing zone** — label the PZ and order pages accordingly, add stores accordingly.
- Edit Details: Available/Valid Sunday–Saturday; **hidden in hosted;** preview = Thursday before go-live; no theme.
- Thumbnails Standard 4. **Legibility heights 45/35.**
- **⚠️ Clear the FTP** — mark files (incl. Posting Document) as uploaded.

### Setup QC (Vendor)
- **⚠️ Confirm all pages uploaded** (PZ tab → Items View); if uploading from SFTP, confirm no un-uploaded pages remain.
- Confirm flyer dates (usually first or last page); complete Standard 4 thumbnails; ensure preview dates set.

## QC specifics

### Box Draw (Low; Auto-Box ON, Box QC bot OFF; no linking doc)
- **Include** coupons, packaged deals. **Exclude** retailer logo, sign-up page, social media, special weblinks.
- Box all items with prices or sales stories; use text boxes when necessary.

### Tag / Tag QC (Low; Auto-tag OFF; no linking doc)
- Include name, pre/postfix, valid dates, description, price, sale story, categories, disclaimer, original price. **Exclude SKU, URLs.** Brand used for both box/tag.
- **Name** includes all items in the ad block. Description as in flyer.
- **⚠️ For items with multiple prices, DO NOT put the second price in the Original Price field.** Put the **Sale Price in Current Price** and the **Coupon/Extra Savings offer in the Sale Story.**
- **Sale Story:** Extra Savings, MFR Rebate, and Digital Coupon callouts (blue box) all go in the Sale Story field.
- **⚠️ Valid dates:** watch for 2-Day / 3-Day sale banners and tag all applicable items with the unique dates.
- **Categories:** every item; Baby → Health & Beauty; Pet → Grocery.

### Image QC
- **⚠️ Currently NOT using PDF images — use item cutouts ONLY.**

## FQC (owned by Flex)
- 1-day preview, available everywhere; complete leftover spotchecks; merge narrow pages in Storefront Spotcheck; mark Autostack Spotcheck complete.
- Review each page for special days (e.g. 3 Day Sales) and apply correct item valid dates.
- Check the weekly insert Google doc — ensure pages placed and labeled/linked correctly.
- Ignore the (non-real) warnings in the FQC checklist and proceed.
- FQC checklist #2: spotchecks, thumbnail QC (Standard 4), legibility heights, geography vs. prior weeks, page order/region, toggles, all items tagged, dates match PDF, no real overview warnings.

## Flyer Review
- **Type: Lite** — flyer dates, sessions complete, previews correct, all items tagged, geography correct, availability toggles correct.
