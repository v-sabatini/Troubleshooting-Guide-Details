## Files & schedule
- **Files received:** ad hoc (retailer confirms upload to FTP; files include the flyer + linking document). Linking document: **Yes.**

## ⚠️ Risk item — links
Incorrect or missing links. In the URL spreadsheet items are ordered by page number (col 1), Sale Name (col 2), URL (col 3). If there are "Learn more" buttons without specific links, adjust the boxes so the link covers the **whole banner** it belongs to (not just the title).

## Upload & setup (owned by DOC)
1. Retailer confirms files on FTP.
2. Internal Run Name = column 2 in the Ren's schedule.
3. Manual upload > Autogroup.
4. Create pricing zones — typically add all stores to **Base**; **check the schedule to see if they want them separate.**
5. Attach linking document to all tasks.
6. No Theme; available everywhere; complete Setup QC checklist.

## QC specifics
- **Box Draw (Low; Auto-Box ON, Box QC bot OFF; linking doc required for Box/Tag):** **include sign-up page, social media, special weblinks**; exclude coupons, packaged deals, retailer logo. Multi-items: include items with multiple prices for sizes in **ONE box**.
- **Tag / Tag QC (Low; Auto-tag ON, PDF image auto-selection ON; linking doc required):** include Brand, Name, Pre/Postfix, Valid Dates, Description, SKU, Price, Sale Story, Categories, Disclaimer, Original Price, URLs.

## Post-processing / FQC (owned by Vendor)
1. **Check URLs:** open linking doc attached to vendor tasks; review every link on each page (**use the correct EN or FR tab**); add a comment "All links checked". Watch "learn more" buttons per the risk item above.
2. Spotchecks (if required); QC thumbnails Standard 4 (Stock premium, storefront carousel premium, storefront carousel organic).
3. Edit Details: Preview 5 AM day before; External Run Name = column 2 in the RP schedule; confirm run dates per the schedule.
4. Autostack spotcheck; items without URL; flyer sorting (One week sale/Grand opening → Month → Grooming/PetPro flyer).
5. Complete Final QC.
- **Send the preview link for any Signature Sales / Weekly Sales publications to the team.**
