## Files & schedule

- **Files received:** Monday.
- **Publication:** Available/Valid Thursday → Wednesday (unless PDFs specify otherwise); preview to client the Tuesday before.
- **Linking document:** client spreadsheet, mass-attached to all Vendor tasks (stored in the run's Drive folder).

## Upload & setup (owned by Flex)

- Files land in the FTP in a folder named with the same date/number as the flyer run (e.g. "10.6" or "106"). Pages are numbered by their flyer order.
- **Pages tab** → Edit → Upload from the corresponding FTP folder → number each page in the index field per file naming → Save & Complete (do **not** process internally).
- **Pricing Zone:** 1 zone named **`Base`**, add all stores; ensure all pages added in correct order.
- Attach the **linking document** to all Vendor tasks (Vendor page → Upload Mass Attachment → All Vendor Assignments → matching-name doc) before starting Setup QC.
- Add the **Category Page** to all Standard runs in the last position.

**Setup QC:** confirm linking doc attached to all vendor tasks first; Available/Valid Thu–Wed with a Tuesday preview date; **Theme = No Theme** (unless Black Friday/Holiday etc.); available everywhere (not hidden); **External Run Name = same as Flyer Run**.

**Fragrance flyers:** enforce **minimum 3 shoppable items per page**; flag pages heavy on direct/category links or low item density early, before processing.

### ⚠️ Common errors / risk items (retailer-specific)

- **URLs — HIGH RISK.** Double-check every URL is linked out correctly; tag per the URL section.
- **Flyer sorting:** if more than one flyer is live at once, the **Sunday flyer must be listed first** on the iframe — set Sunday flyers to go live 12:01 and Flyer Sorting to "Newest First."
- **Box drawing:** if more than one item shares a square and has a URL, **box them separately**. But items with the **same** link → the retailer prefers one big box. **Boscov's Bargain Outlet** (top half of the page) → one giant link, not individual items.
- **Sale story:** watch for multiple sale stories on one page; use the layout to apply the correct one.
- **Setup QC alerts:** "This flyer is a primary publication" → check the box and proceed. "Item Tag/Item QC missing an attachment/note" → linking doc not attached to all vendor tasks; attach it, then restart Setup QC.

## QC specifics

- **Box Draw — HIGH complexity. Auto-Box ON, Box QC bot ON. Linking doc required.** Include coupons, packaged deals, retailer logo, sign-up page, social media, special weblinks. Category page: box all categories including "Shop Our Top Categories" — box the entire photo + CTA, not just the CTA.
- **Tag / Tag QC — Medium. Auto-tag OFF. Linking doc required.** Include name, pre/postfix, valid dates, description, SKU, price, sale story, categories, disclaimer, original price, URLs. **Online # = SKU.** Multiple items in one box → put one item's price in Current/Original, all other prices go in Description. Current price range → range from current price into postfix; original price range → enter lowest only. **Category page** tagged as links with fixed URLs (week-over-week same). Bargain Outlet tagged as a link.
- **Image QC:** PDFs preferred when clean (no shadows/black marks, entire product visible).

## FQC / go-live (owned by DOC)

- **Links QC:** download linking doc; Overview → Item Search → URL IS blank; compare blanks to the linking doc and add links until none remain.
- **Thumbnails (standard 4):** thumbnail_1065_x_600 (2 pages), stock_premium (1 page), storefront_carousel_premium (2 pages), storefront_carousel_organic (1 page).
- Insert/Weekend pages — set triggers per the file-drop email; after-hours live-check ticket due Wednesday before go-live.
- Download category page from Drive, box/tag it (can copy from prior run), insert last.
- External Run Name usually **"Boscov's Weekly"**; send preview link Wednesday before go-live and apply returned revisions.
- **Flyer Review type: Medium.**

## Out-of-processing

- Page swaps: standard baseline process.
