## Files & schedule (Weekly)

- **When files arrive:** Monday.
- **Publication cadence:** Available From Tuesday · Valid From Thursday · Available To Monday · Valid To Tuesday.
- **Preview date:** Sunday (set "Preview start date" = the Sunday before the available date).
- **Article Numbers** entered ~2 days out (FLEX); FQC ~1 day out (DOC).

## Upload & setup (owned by FLEX)

- Weekly Flyer = codesheet upload with manual stores troubleshooting (flyer type **6006**). General Merchandise = flyer type **10554** (owned by Docs).
- **⚠️ NEW 2026 — Set Pixel Height to 4096 BEFORE uploading any pages.** Open flyer run → Edit Details → Show/hide rarely-used fields → Height dropdown → select **4096.0 pixels** → OK. If pages were already added before this step, flag the Full-Time Ops stakeholder and continue.

### ⚠️ Common errors / risk items (retailer-specific)

- **PC Optimum buttons:** tag every "PC Optimum" button with the `pcoptimum.ca` link.
- **Joe Fresh pages:** tag all Joe Fresh items as **ONE box** and as a **direct link**.

## QC specifics

- **Box Draw (Medium; Auto-Box ON, Box QC bot ON).** No linking doc required. **Include:** items with a unique price, coupons, packaged deals, special weblinks, PC offers with a URL. **Exclude:** retailer logo, sign-up page, social media.
- **Tag / Tag QC (Low; Auto-tag OFF).** Linking document required (Tag/QC specific). Include name, pre/postfix, valid dates, description, SKU, price, sale story, categories, disclaimer, original price, URLs. Brand handled via Box Draw/Box QC.
  - **Name/Brand:** ALL CAPS; format "Brand Product Name, Quantity" (always a comma before quantity); product name is the bold text; **English only**. Do NOT include in the name: alternate-unit metrics (e.g. "6.59/kg"), "Product of…", "No 1 Grade", "Frozen", "Selected varieties".
  - **Description:** only descriptive info from the flyer (never from the website). French pages: English description at top, then French name/description a few lines below (not bold); first letter capitalized; put alternate-unit metrics and "Product of…"/"No 1 Grade"/"Frozen"/"Selected varieties" here. Do not put SKU in description.
  - **Article Numbers** (special fields at bottom of Tag interface): paste the Product SKU, one per field, including the unit of measure (`_KG`, `_EA`, `_LB`, `_C12`, `_C24`, etc.). Article Number 1 = same SKU as SKU/Fetch URL fields. Multiple SKUs → 1st→AN1, 2nd→AN2, 3rd→AN3, 4th→AN4.
- **Image QC:** complete as usual — PDF preferred unless the image is unclear.

## Post-processing (owned by DOC)

- **URL/Links QC:** reference the Final Codes; links are in the Notes/URL's section (column E). Open those pages and box the linked area (usually the header, or a "Click Here"/"Shop Now" button). Tag as **Direct Link, not Item.**
- Item Category QC, Item Image QC, SKU QC, Ad-Hoc QC, Final QC Checklist.

## Flyer review / out-of-processing

- **Out-of-processing — Page Swap:** standard page swap.
