## Flyer shell creation (owned by Flex)

On receiving a file-drop email: identify valid dates (last page of PDF or email); check if a shell exists (if so skip to adding to Processing Support). If not: View Runs for the correct Flyer Type (**Guide** for anything labelled Guide, **Weekly** for all others) → Create New Flyer Run → Available and Valid dates the SAME (no preview day), internal run name based on flyer name → OK. Add run to Processing Support and confirm receipt by email.

## Upload & setup (owned by Vendor)

- Manual upload — select files from FTP for print/online. **Folders are named after the live date in `MMDDYY`** (e.g. live Nov 9 2022 → folder `110922 PDFS`). Files upload early, so expand the "Month" tab to find the folder.
- Autogroup (online usually better); for print, manually group then priority normal.
- 1 pricing zone named "base"; add all stores ("Add all").
- Ensure external run name **"Weekly Ad"**; check FTP that all week's files are uploaded.

### Setup QC checklist
- Key messages from page 1 or "This Week's Deals" if no page-1 callout. Check dates on the last/second-last page bottom.
- Thumbnail QC — logo and name present.
- Check off all uploaded files in the Lewis Drug FTP.
- **Any ad under Flyer Type "GUIDE" must have its linking doc attached to all Vendor tasks.**

**Special ads (content policy):** ads over 3 pages need avg 3 shoppable items/page; under 3 pages need 6 shoppable items (name, price, imagery). If it fails content policy, it goes live **hosted only** (hide in distribution and Flipp; leave a note).

## ⚠️ Common errors / risk items

- **Flyer sorting:** the "Weekly" Ad(s) must **ALWAYS be first**.
- **Page order:** pages are often scrambled in the FTP — check page numbers and re-arrange in ascending order.
- **Shell creation:** create a shell for each ad-hoc publication once the file-drop email is received.

## QC specifics

- **Box Draw (Medium; Auto-Box OFF, Box QC bot OFF):** include coupons and packaged deals; exclude retailer logo, sign-up page, social media, special weblinks. Box every item with a unique price; use text boxes as needed. **Coupons:** box the coupon and any embedded promotion, tag as an item (promotion in sale story, details in disclaimer).
- **Tag / Tag QC (Low; Auto-tag ON; PDF image auto-select ON):** include name, pre/postfix, valid dates, description, price, sale story, categories, disclaimer, original price. **Exclude SKU and URLs.** No tagging doc for Weekly ads; Guides use their attached tagging doc.
  - **Original Price = the "Compare to" price** (e.g. COMPARE TO 59.99).
  - Page-level callouts (e.g. "10 for $10", "BUY ANY 5 … WITH LEWIS APP") apply to every item on that page (prefix or sale story).
  - **Coupons:** select "do not use PDF image"; add "Coupon" to the end of the name; tag category "Coupon".
  - **Guides — price ranges:** if not a range, Current Price = "NOW"/red price, Original Price = "Compare to". If a range (e.g. $25–$50), put current range in **Prefix** and original range in **Postfix**.
  - **Flowers grid:** each flower tagged with its own name (e.g. "Salzburg Shadow 11\" Combo Hanging Basket"); prefix/price same for all following the first basket.
  - Every item needs a category (chart provided in the guide: Toys, Seasonal, Pharmacy, Pets, Outdoor Living, Home Essentials, Health & Beauty, Grocery, Grills, Gifts, Coupon, Beverages, Beer/Wine & Liquor).
- **Image QC:** select an image for every item; prefer clean white-background PDF, else cutout.

## FQC (owned by Flex)

- External Run Name: "Weekly Ad" for Weekly and Milbank ads; ad-hoc = match page-1 callout.
- Page Category QC: category on all pages except page 1; pages with grills tagged Grills.
- Standard 4 thumbnails; stores assigned; "Mark Items in store only" on overview.
- Check off all uploaded FTP files. **Risk:** confirm page order (ascending). **Risk:** flyer sorting — Weekly Ad first.
- Item Category QC (Flex): ensure Google + Analytical category.
- **Out-of-processing:** standard page swap.
