## Files & schedule

- **Files arrive:** ad-hoc. Files sometimes come through BD in the Slack channel, other times from the client directly.
- **Cadence:** Available/Valid From/To all ad-hoc.

## Upload & setup (owned by Vendor)

- **Manual upload:** Pages → Edit → select all pages from SFTP. The folder is named after the flyer valid date — **always use the lowercase folder, never the Upper Case folder.** Confirm & Upload. Auto-Group; Save & Complete.
- **Pricing zone:** create one PZ "Base", add all stores, Save & Complete.

### Setup QC
- Confirm all pages uploaded: SFTP should have no pages remaining except the multi-page PDF (Upper Case name not ending in "P####"). Flag missed pages to the FT team.
- Confirm valid dates match page 1 of the PDF. Thumbnails Standard 4.
- **Geography: 0 changes to Stores or FSAs** — flag 100% of any discrepancies to the FT team (but continue the checklist).
- Platform toggles: available on **all** platforms.

## QC specifics

- **Box Draw (Low; Auto-Box ON, Box QC bot OFF):** no linking doc. **Include packaged deals.** Exclude coupons, retailer logo, sign-up page, social media, special weblinks.
- **Tag / Tag QC (Low; Auto-tag ON):** linking doc required (tag-specific). **Include** image (always select a clean PDF if available), brand, name, pre/postfix, valid dates, description, price, sale story, categories, disclaimer, original price. **Exclude** SKU, URLs. Standard tagging = PDF details + URL from linking doc if provided.

## Final QC / go-live notes (owned by Vendor)

- Confirm valid dates (per PDF); available everywhere; thumbnails drawn incl. retailer logo.
- All items boxed/tagged; previews clickable; **geography consistent with last week** — immediately flag 100% of discrepancies to FT Ops (does not block your work).
- **Flyer Review type: Lite.**
