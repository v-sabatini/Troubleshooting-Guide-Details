## Files & schedule

- **Files received:** Saturday (dropped to FTP with a Posting Document; client emails when files land).
- **Cadence:** Available/Valid Sunday → Saturday.
- **Preview:** set for the Thursday before go-live.
- **Setup owned by** Vendor; FQC owned by Vendor.

## Upload & setup

- Download the **Posting Document** to confirm page order; upload pages from FTP and order per the Posting Document.
- **Pricing Zones:** one zone named **Base**; add all stores (1 store — #1).
- Wait for sessions; confirm vendor tasks active.
- Edit Details: Available/Valid Sunday→Saturday; **Available on Flipp and Distribution, Hidden in Hosted**; preview Thursday before go-live; **no theme**.
- Thumbnails: Standard 4. **Leg heights 45/35.**
- Clear all FTP files (including the Posting Document) when done.

### ⚠️ Common errors / risk items
- **Uploading from SFTP:** confirm no pages remain in the SFTP that weren't uploaded.
- Pages may need to be added to the SFTP by the processor if the client sends files over email.
- Watch for **3-Day / 2-Day sale banners** — tag those items with the unique valid dates.

## QC specifics

- **Box Draw (Low; Auto-Box ON, Box QC bot OFF):** include coupons and packaged deals; exclude retailer logo, sign-up page, social media, special weblinks. Box each item individually.
- **Tag / Tag QC (Low; Auto-tag OFF):** include name, pre/postfix, valid dates, description, price, sale story, categories, disclaimer, original price. **Exclude SKU and URLs.** Brand used for both box/tag.
  - **Multiple prices:** do NOT put the second price in Original Price — put the "Sale Price" in Current Price and the "Coupon/Extra Savings" offer in the Sale Story.
  - Item categories required on every item. **Baby → "Health and Beauty"; Pet → "Grocery."**
- **Image QC:** **NOT using PDF images — use item cutouts ONLY.** (Also applies to spotchecks.)

## Final QC / go-live notes

- Pre-FQC: complete any spotchecks; check "Storefront Spotcheck" for narrow pages per pricing zone and merge to next page; review special-day pages (e.g. 3-Day sales) for correct valid dates.
- FQC checklist: spot checks, thumbnails (Standard 4), leg heights, geography vs. prior weeks, page order/region, toggles, all items tagged, dates match PDF, no "real" overview warnings.
- **Flyer Review type: Lite.**
