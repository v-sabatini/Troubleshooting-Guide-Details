## Upload & setup

- **Manual Upload:** Pages Tab → Edit → select all pages from the SFTP menu → Autogroup pages (**English pages only**) → Save & Confirm. **Do NOT Process Internally.**
- **Pricing Zone Creation:** one zone (call it **Base**); add all stores (5).
- Setup QC: confirm all pages uploaded (Pricing Zone Tab → Items View); confirm flyer dates; Thumbnails (4 Standard); **No Theme, No External Run Name.**

### ⚠️ Common errors / risk items
- **Uploading from SFTP:** confirm no pages remain in the SFTP that weren't uploaded.

## QC specifics

- **Box Draw (Low; Auto-Box ON, Box QC bot OFF):** exclude coupons, packaged deals, retailer logo, sign-up page, social media, special weblinks. Box all single items; box items separately when multiple appear in one image (only the main pictured item gets the image, the rest capture text only — do **not** draw as text boxes).
- **Tag / Tag QC (Low; Auto-tag OFF, PDF Image Auto Selection ON):** include name, pre/postfix, valid dates, description, price, sale story, categories, disclaimer, original price. **Exclude SKU and URLs.** Brand used for both box/tag.
- **Image QC:** Standard — PDF preferred if clean, otherwise cutouts accepted.
- **Spotchecks:** standard pricing spotchecks in pipeline (pricing discrepancies / uncommon Name info).

## Final QC / go-live notes

- Pre-FQC: confirm dates vs. PDF; availability toggles; thumbnails include retailer logo; all items boxed/tagged; spotchecks complete (20% of pricing zones); previews published & clickable; sessions complete; geography correct.
- **Flyer Review type: Lite** — no extra boxes drawn during autobox; geography may change WoW based on distribution instructions.
