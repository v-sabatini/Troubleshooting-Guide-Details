## ⚠️ #1 Risk item — Valid/Available dates
The **Available To** date/time is **3 hours AFTER** the Valid To — this is correct. Example: Available Wed Aug 6 3:00 AM → Available To Thu Aug 14 2:59 AM; Valid Thu Aug 7 3:00 AM → Valid To Wed Aug 13 11:59 pm. **The Available-To and Valid-To dates must NOT be the same.**

## Upload & setup (owned by Vendor)
- Download/open `/QF.xlsx` from the fadmin FTP — use the file from the week you're working on. No manipulations needed.
- Upload codesheet: Name = "Upload"; codesheet added from sFTP; **Config `overwaitea`**; PDF Base Directory taken directly from sFTP. **Toggles 1, 3, 4 and 6.**
- Mark flyer creation complete — **stores are pulled in after running the codesheet.**
- Check sFTP to confirm all pages uploaded.

### Setup QC
- Flyer Details: External Run Name = "Weekly Ad"; No Theme. Confirm logo is prominent.
- Thumbnails: Standard 4 (Thumbnail 1065x600 first two pages, Stock premium first page, Storefront carousel premium first two pages, Storefront carousel organic first page).

## QC specifics
- **Box Draw (Low; Auto-Box OFF, Box QC bot OFF):** exclude coupons, packaged deals, retailer logo, sign-up page, social media, special weblinks. Box all items in their blocks that share prices/descriptions; box each App-download block individually; box multiple items individually with text boxes where needed.
- **Tag / Tag QC (Low; Auto-tag ON, PDF image auto-selection ON):** include Name, Description, SKU, Price, Sale Story, Categories, Disclaimer, Original Price. Exclude Pre/Postfix, Valid Dates, URLs. Brand is Box Draw/Box QC specific.
- **Image QC:** prefer clean PDF images if available (e.g. Island Farmhouse chicken breast, Western Family Greek yogurt).

## Post-processing
- **Item Category QC (DOC):** choose 1 of the most valid categories; do NOT add a category to page 1.
- **FQC (DOC):** mark auto-stack off; External Run Name = "Weekly Ad"; No Theme; available everywhere; check geography; page categories on all but first page; Image QC = review cutouts only, pick clean PDF images if available else cutout; check special sale dates; confirm dates (Avail Wed 3 AM – Thu 2:59 AM, Valid Thu 3 AM – Wed 11:59 pm); check horizontal/vertical previews; Standard 4 thumbnails; flyer sorting = current Weekly, Preview next week, Monthly.
