## Files & schedule
- **When files arrive:** 1–2 weeks lead time.
- **Publication cadence:** 4 runs (Hunts typically run four days; **each day is its own one-day flyer run**).
- **Linking document:** provided by Design.

## Pre-setup (owned by DOC)
- If flyer runs don't exist, create them per the Design team's instructions (see the Egg Hunt planning document). Provide flyer run IDs in that document.
- Create **four one-day runs** in Flyer Type #9907 (FlippCA merchant) and **four one-day runs** in Flyer Type #9908 (FlippUS merchant).
- Overview → Edit Details: confirm each run is one day, **12 AM to 11:59 PM** (per Design). Set the **External Run Name** to the Visible Name(s) from the planning document.
- Create ClickUp ticket(s) for each flyer run; attach all assets (EN + FR flyer PDFs, custom thumbnail JPGs). Provide the correct **Terms & Conditions link per run** in a comment — **⚠️ there is a different link for each run.**

## Upload & setup (owned by Vendor) — manual upload
- Manual upload of all flyer assets (provided in the ClickUp ticket): Pages → Edit → Upload File from local drive.
  - **FlippCA:** gets an English AND a French page — toggle the French asset to French.
  - **FlippUS:** gets just the English version.
- Flyer Creation → Start Task:
  - **FlippCA:** create **two** pricing zones — **EN** and **FR**; assign the English page to EN and French page to FR, setting languages accordingly.
  - **FlippUS:** create **one** pricing zone — **National**; assign the English page.
- Pricing Zone → Assign Regions:
  - **FlippCA:** under FSAs click the **0**, then on the Region Assignment page click **National** for both English and French versions (highlights grey).
  - **FlippUS:** under FSAs click the **0**, click **National** (highlights grey).
  - Return to the Pricing Zone tab and refresh — the 0 under FSA should now be a number for every zone.
- Thumbnails: download the custom thumbnail JPEGs from the ClickUp ticket; assign to **Storefront Premium** and **Storefront Carousel Premium** (Choose File → upload). Mark Complete.

### Setup QC (owned by Vendor)
- The flyer gets **one item total**, boxed and tagged. Either add the correct run's link (from the ClickUp ticket) in the comment of the **Vendor Tag** and **Vendor Tag QC** tasks, or start Vendor Box and box/tag it yourself to make it immediately available for FQC.

## QC specifics

### Box Draw (Low complexity — Auto-Box OFF, Box QC bot OFF; linking doc required)
- **Include special weblinks:** box **only the Terms and Conditions image** at the bottom of the page (look for the words "Terms and Conditions"). One link, provided in the ClickUp ticket / Vendor Task comment.
- **Exclude everything else** — coupons, packaged deals, retailer logo, sign-up page, social media, and the rest of the flyer.

### Tag / Tag QC (Low complexity — Auto-tag OFF)
- **Exclude all fields** (name, pre/postfix, valid dates, description, SKU, price, sale story, categories, disclaimer, original price, brand, PDF image auto-selection).
- **Include URLs only:** assign the one link from the comment box and set the **Item Type to Link**.

## Post-processing / FQC (owned by DOC)
- **⚠️ URL/Links QC — most valuable check:** each flyer run is one day only with a unique link per day. Refer to the ClickUp task for the list of links; use the flyer run name to identify the day. Open the Tag interface for **every page version** and confirm the **correct day's link is applied** — if not, update and resave.
- Check thumbnails (re-add custom thumbnails if missing from Storefront Premium / Carousel Premium).
- **Check Zones FSAs:** FlippCA should have EN + FR versions; FlippUS should have National. Confirm all zones assigned the **National** region. **Do this FSA check in place of the Geography check** — the Geography tab may not compare runs due to the gap between Hunts.
- Complete Final QC checklist.
