## Files & schedule

- **Files arrive:** ad-hoc (uploaded to FTP with pages + linking doc).
- **Cadence:** Available/Valid From/To all ad-hoc.
- **Workflow:** Upload & Setup (Vendor) → Image QC (Flex) → FQC (DOC).

## Upload & setup (owned by Vendor)

- **Manual upload** of pages via FTP. Number all pages; toggle **FR** for all French pages, then Save → Save and Complete.
- **Pricing zones:** PZ 1 = **ENG** (all English pages, in order); PZ 2 = **FR** (all French pages, in order). Save and Done.
- Add **all stores** to both PZs.
- Attach the tagging/linking document to **all vendor tasks** (must be **.xls** format — Vendors → upload mass attachment → select all vendors → choose the xls).
- Wait for sessions to run. **Confirm the French and English flyers match** — flag to processor if not. Thumbnails: **Standard 4**.

### Setup QC
- Dates on the very last page (bottom) — confirm they match what the retailer states.
- No theme; available everywhere.

## QC specifics

- **Box Draw (Low; Auto-Box OFF, Box QC bot OFF):** linking document required (box-specific). **Exclude** coupons, packaged deals, retailer logo, sign-up page, social media, special weblinks. Box each item individually; use text boxes around the description that corresponds to the image for multiple deals; box banners with calls to action.
- **Tag / Tag QC (Low; Auto-tag OFF):** linking document required (tag-specific). **Include** brand, name, description, price, sale story, categories, disclaimer, original price, URLs. **Exclude** pre/postfix, valid dates, SKU.
- **Image QC:** choose white-background PDF images where possible, otherwise the cutout.

## Final QC / go-live notes (owned by Flex)

- **Check all URLs:** open the linking doc attached to Vendor Tasks, review every link on each page (using the correct EN or FR tab), then note "All links checked" in comments.
- Spotchecks if required. QC thumbnails Standard 4 (stock premium, storefront carousel premium, storefront carousel organic).
- Edit Details: available everywhere, no external run name, run dates match the last PDF page. Check items without URL.
- **Processor sends the preview to the retailer the day before go-live.**
- Flag any missing pages or geography changes to the full-time team.
- **Flyer Review type: Lite.**
