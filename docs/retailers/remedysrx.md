## Files & schedule
- **Files received:** Monday. Available From Monday; Valid From Tuesday (2-day early consumer preview — available 2 days before valid). No linking document.

## Upload & setup (owned by Flex)
- **Manual upload with a generic store codesheet uploaded during Setup QC or FQC.**
- Pages > Edit > select the ad files you're working on (the monthly ones) > Save > Auto-group > Save and next.
- Flyer Creation: create one PZ named **"Base"**.
- **Stores:** use the "Digital Posting Run List" for the ad — this file holds the relevant stores to manipulate and upload as a **generic store codesheet** (see the setup video referenced in the OneGuide).

### Setup QC
- Check dates on the first page (Overview > Edit Details): **2-day early consumer preview**, Valid Date 2 days after available. No external run name; No Theme; Thumbnails Standard 4.

## QC specifics
- **Box Draw (Low; Auto-Box ON, Box QC bot ON):** **include retailer logo, sign-up page, social media, special weblinks**; exclude coupons, packaged deals.
- **Tag / Tag QC (Low; Auto-tag ON):** include Name, Pre/Postfix, Description, Price, Sale Story, Categories, Disclaimer, Original Price; Brand is Box Draw/Box QC specific; **exclude Valid Dates, SKU, URLs.**
- **Image QC: n/a — no Image QC.** No spotchecks.

## Post-processing / FQC (owned by Flex)
- QC Thumbnails Standard 4; leg heights 40/30; no image QC.
- **Add the stores via the generic store codesheet.**
- Check sessions good; No Theme; no external run name; mark FQC checklist off.
