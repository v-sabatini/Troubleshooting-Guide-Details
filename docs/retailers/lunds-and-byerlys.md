## Files & schedule

- **Files received:** Monday (inconsistent / short lead time), via SFTP with email confirmation.
- **Cadence:** Available Thu–Thu; Valid Wed–Wed.
- **Preview date:** N/A (no customer preview date).

## Upload & setup

- **Manual upload:** Pages → Edit → select all pages from the FTP menu. Group pages by naming convention (Pg. 1 = Grouping 1); **Promo Page always last**. English only. Save & confirm.
- **Pricing zone:** manually create one version named **"Base"** with all pages in numerical order. Save, then add all stores.
- **Setup QC:** confirm dates (against page 1), complete standard-4 thumbnails, **no theme / no external run name**.

### ⚠️ Common errors (retailer-specific)

- **SFTP page check** — when uploading from SFTP, confirm there are **no pages in the SFTP that weren't uploaded** for that week.
- Watch for **multiple products** that must be boxed/tagged separately.

## QC specifics

- **Box Draw (Low; Auto-Box ON, Box QC bot ON).** No linking doc. **Exclude** coupons, packaged deals, retailer logo, sign-up page, social media, special weblinks.
  - Box single items (image + text). Items sharing one price → boxed together. Some banners contain multiple items → box/tag each separately (e.g. Buzzballz Chillers vs On the Rocks; Coho Salmon vs Wild Jumbo Shrimp).
- **Tag / Tag QC (Low; Auto-tag ON; PDF image auto-selection OFF).** Include brand, name, pre/postfix, valid dates, description, price, sale story, categories, disclaimer, original price; **exclude SKU and URLs.**
  - Tag item-level valid to/from dates when a sale starts/ends on dates that don't match the flyer's valid dates.
- **Image QC:** standard.

## FQC / flyer review

- Confirm dates (page 1, no preview date); availability toggles all unchecked; **standard-4 thumbnails incl. retailer logo — page 2 is odd-sized, use wider thumbnails**; legibility heights (40, 30); all items boxed/tagged; spotchecks complete; previews clickable; sessions complete; geography same WoW (**29 stores assigned**).
- **Flyer Review type: Lite.**
