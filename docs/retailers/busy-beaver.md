## Files & schedule

- **Files received:** Thursday.
- **Publication cadence:** Available From Sunday · Available To Tuesday · Valid From Wednesday · Valid To Tuesday. Flyer can run **one week OR two weeks** — always confirm the run length.
- **Linking documents:** yes — Flyer Linking Document per zone, attached to all vendor tasks from the FTP (e.g. `…Zone A.xlsx`, `…Zone B.xlsx`).

## Upload & setup (owned by DOC)

- **Manual Upload:** Pages Tab → Edit. Select all pages for zones A and B from the SFTP menu. Files may need to be added to the SFTP by the processor if the client sends over email. Confirm files share the flyer run date → Confirm & Upload. Auto-group pages into Grouping Number → Save & Confirm. **Do NOT process internally.**
- **Pricing Zone Creation:** Start flyer creation → create two pricing zones, **Zone A** and **Zone B**. Zone name is in the file name; add pages to the correct zone. Save & Confirm.
  - **Zone B stores:** 2001 Lincoln Way and Ellwood-Zelienople Rd. **All other stores → Zone A.**

### Setup QC
- Confirm all pages uploaded (Pricing Zone → Items View); **check the SFTP for any un-uploaded pages.**
- Confirm flyer dates at top of page 1 — verify one-week vs two-week run length.
- Thumbnails 4 Standard; set all preview dates; attach linking documents for both zones to all vendor tasks.

## ⚠️ Common errors / risk items
- **Dates:** confirm whether the flyer runs one week or two.
- **Upload:** the contact does **not** email when files are dropped — check the SFTP proactively.

## QC specifics

### Box Draw (Low; Auto-Box ON, Box QC bot OFF)
- **Exclude:** coupons, packaged deals (e.g. washers/dryers), retailer logo, sign-up page, social media, special weblinks.

### Tag / Tag QC (Low; Auto-tag ON)
- Linking document required (Tag/QC-specific).
- **Include:** brand (used for box + tag), name, pre/postfix, valid dates, description, SKU, price, sale story, categories, disclaimer, original price, URLs.
- Use the URL from the tagging document.

### Image QC
- PDF preferred if clean; otherwise cutouts accepted. (Flex also does a post-processing Item Image QC.)

## FQC / flyer review
- Confirm dates: Available Sunday→Tuesday (available two weeks); Valid Wednesday→Tuesday (matches PDF).
- Confirm availability toggles (available everywhere); no items without URL (add from linking doc).
- **Page 1s carry a "weekend specials" item with different valid dates from the flyer run** — open every page 1 and confirm those valid dates are added.
- Thumbnails include the retailer logo; standard checks (all boxed/tagged, spotchecks 20% of pricing zones, previews clickable, sessions complete, geography correct).
- **Flyer Review type: Lite.**
