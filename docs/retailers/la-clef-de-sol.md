## Files & schedule

- **Files arrive:** ad-hoc.
- **Cadence:** Available From Friday / Valid From Thursday → Available To Friday / Valid To Thursday.
- **Workflow:** Upload & Setup (Vendor) → Image QC (Flex) → FQC (DOC).

## Upload & setup (owned by Vendor)

- **Manually upload** pages via SFTP (no codesheet).
- Toggle **French only** and auto-group the pages.
- **Pricing zones:** (1) Base (mainly French); (2) Base cl (cross language). Add all stores (only 1 PZ of stores).
- Once OS processes, go to FQC.

## QC specifics

- **Box Draw (Low; Auto-Box OFF, Box QC bot ON):** no linking doc. **Exclude** coupons, packaged deals, retailer logo, sign-up page, social media, special weblinks. Box any item with a price; use text boxes as required.
- **Tag / Tag QC (Low; Auto-tag ON):** no linking doc. **Include** brand, name, pre/postfix, valid dates, description, SKU, price, sale story, categories, disclaimer, original price. **Exclude URLs.** Fields filled from the PDF.

## Final QC / go-live notes (owned by DOC)

- **Cutouts only** for images.
- 4 thumbnails; legibility heights **45/35**.
- **Hidden hosted.**
- No theme (possible theme for Black Friday / Holiday ads).
- Available from/to and valid from/to are the same.
- **Risk items:** ensure all text boxes are boxed (sale story and price); watch for cut-up cutout images during vertical preview / storefront spotcheck — if cut up, merge the pages; re-run any sessions that need running; geography no changes week over week.
- **Flyer Review type: Lite.**
