## Files & schedule

- **Files received:** Ad Hoc; dates provided on the flyer (usually first or last page).
- **Publication cadence:** Available/Valid From & To all Ad Hoc.
- **Linking Document:** N/A (Tag/QC uses a linking doc where shared).
- Flex-owned pipeline (Setup + FQC owned by FLEX; Flyer Review owned by DOL).

## Upload & setup (owned by FLEX)

- Pages may need to be added to the SFTP by the processor if the client sends files over email.
- **Manual upload:** Pages tab → Edit → select all pages from SFTP (or upload from email) → Confirm & Upload → Auto-Group or manually enter page numbers → ensure **English** language selected → Save & Confirm.
- **Pricing Zone:** create Base pricing zone, select all applicable pages, Save & Confirm, add all stores.

### Setup QC
- Confirm all pages uploaded correctly (Pricing Zone tab → Items View). **Risk:** confirm no SFTP pages were left un-uploaded.
- Confirm flyer dates (usually first/last page); complete thumbnails (Standard 4); complete Setup QC checklist.

## ⚠️ Common errors / risk items (retailer-specific)

- **Look for multiple products** on an item.
- **SFTP upload risk:** confirm there are no un-uploaded pages in the SFTP.

## QC specifics

### Box Draw (Low; Auto-Box ON, Box QC bot OFF)
- Linking Document required (Tag/QC-specific).
- **Include:** packaged deals, special weblinks (if a link is associated). **Exclude:** coupons, retailer logo, sign-up page, social media.

### Tag / Tag QC (Low; Auto-tag ON; PDF Auto Image Selection ON)
- Linking Document required (Tag/QC-specific).
- **Include:** name, pre/postfix, valid dates, description, SKU, price, sale story, categories, disclaimer, original price, URLs, Brand.
- Standard processing: large title text = Name; enter Price; all other text in Description. Tag exactly as shown and include details from the linking document.

### Image QC
- Standard Image QC — PDF preferred if clean, otherwise cutouts accepted.

## FQC (Flyer Review type: Lite, owned by DOL)
- Confirm dates (per PDF) and availability toggles; thumbnails correct incl. retailer logo.
- Standard checks: all items boxed and tagged, spotchecks complete (20% of pricing zones), previews published correctly and clickable, sessions completed accurately, geography correct.
