## Files & schedule
- **Files received:** Wednesday. Available & Valid From Wednesday; Available To Thursday; Valid To Wednesday. **1-day consumer preview.**
- Linking document (**web links xls**) provided via email from the retailer ops contact.

## ⚠️ Risk items
- **"# for #" deals** (e.g. "3 for 2" / "3 pour 2"): leave **Prefix, Current Price, and Postfix BLANK**; enter the deal (e.g. "3 for 2") in the **Sale Story**. Tagging this wrong costs the retailer money since they must honour the deal.
- **URLs & Web links:** ALL web links on the vendor attachment must be added during box/tag. **No RONA URLs — only renodepot.com.** Tag the item URL by visiting renodepot.ca (select EN for English pages, FR for French), search by SKU from the PDF, copy the item URL into the URL field.
- **Slicing:** slice pages to keep the page code visible on the side of every page (e.g. "R04 - WEST LW_W21") — the retailer wants these codes visible for all pages.

## Upload & setup (Weekly owned by DOC; Catalog owned by Flex)
1. Download the web links xls (emailed by the retailer ops contact).
2. Pages > Edit > select the week's files and upload > Auto-group.
3. Toggle all FR pages to French language > Save and complete.
4. Flyer Creation: create **two zones — "1R (EN)"** (all English pages) and **"1R (FR)"** (all French pages) > Save and continue; wait for sessions.
5. Add **all stores to both zones**.
6. Attach the web links document to all tasks for both EN and FR.
7. Complete thumbnails (Standard 4) and Setup QC.
- (The setup video is outdated — no codesheet upload anymore, it's a simple manual upload.)

### Setup QC
- Confirm dates (first page; 1-day consumer preview); sessions complete; vendor tasks assigned with the attachment. Optional note to vendors: box/tag all items incl. web-links items, **no www.rona.com URLs — all URLs must be renodepot.com.**

## QC specifics
- **Box Draw (High; Auto-Box OFF, Box QC bot OFF; linking doc required for Box/Tag):** **include** coupons, packaged deals, logo, sign-up, social, special weblinks. One box per item if it has a SKU. **Multi-SKU items** (labels "A", "B") boxed/tagged separately unless the web links doc says otherwise. Items with different prices → box/tag each SKU separately. Check the web links doc for banners/items needing special links.
- **Tag / Tag QC (High; Auto-tag OFF; linking doc required — Tag/QC specific):** include Name, Pre/Postfix, Valid Dates, Description, SKU, Price, Categories, Disclaimer, Original Price; Brand used for both Box/Tag; **Sale Story and URLs are Risk Items.**
  - Add the **Brand in the Name field** alongside the name (as on the PDF); put multiple dimensions in the name, not the description. Include the SKU in the description.
  - Reference discount callouts in EN and FR; include "SPECIAL VALUE" / "NEW LOWER PRICE!" in the sale story in addition to the discount (e.g. "1/2 PRICE", "2 FOR 1", "SAVE $50", "RABAIS DE 25%", "7 POUR 6"). For sales callouts, ONLY a sale story, NO current price.
  - Every item needs a URL in the matching language (EN pages → EN URL, FR pages → FR URL); used to data-pipe images/descriptions. Search the **last part of the SKU only** (never the full SKU or the SKU within the bracket; for multi-SKU, don't include numbers after the "/"). All links must be **direct** — never a search page. If not found, leave URL blank.
- **Prefix/Postfix QC:** reference the OneGuide's lists of commonly used EN/FR prefixes and postfixes.
- **Image QC:** select the **data-piped image if available** (data piping ≥ 80%); else clean PDF; else cutout. Tool-kit / items sold separately (A, B) → box/tag separately, select clean PDF of the individual item if no data-piped image.

## Post-processing (owned by DOC)
- **Sales Story / Prefix QC:** file a FAB ticket (clone the reference ticket in the OneGuide).
- **URL/Links QC:** check tagged pages against the web links doc; confirm promo banners/special-link items boxed & tagged; **Item Search URL contains "rona" → should be blank**, else correct.
- **Ad-hoc / corrections:** corrections arrive via an xls from the retailer ops contact — find the flagged item and update URL/tagging/boxing. (MPQC no longer done.)
- **FQC:** Ops spotchecks; thumbnails; **data-pipe all** (missing/errored images) until high 80%+; leg heights auto; **boxing QC — all groupings must have the same box count** (e.g. if page 1 of group 1 has 19 boxes, every page in group 1 should). QC links: item search "/en" language French / "/fr" language English / "rona" → 0; fix wrong-language links. Verify web links match the doc by name. QC categories (Plumbing = pipes only, Hardware = door knobs/bolts/keypads only, Smart Home = smart items only) and sale story (prefix contains for/pour). Flyer sorting: weekly first, then catalogs. **Apply UTM/tracking codes** (cm_mmc and utm_campaign — update week/year per previous run).
