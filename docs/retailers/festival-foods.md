## Upload & setup (owned by DOC)

- Upload process is the **same for organic and promoted/paid** flyers, but watch the matrix sheet for each version:
  - **Organic** flyer → build codesheet from `xxxxxx_MATRIX_FLIPP_ORGANIC.xlsx`.
  - **Promoted/paid** flyer → build codesheet from `xxxxxx_MATRIX_FLIPP_PAID.xlsx`.
- **Codesheet creation:**
  1. Find both matrix files (paid + organic) in the sFTP.
  2. Copy the first three columns (**skip the first row**) into the "Generator" tab of the Festival Foods Codesheets sheet.
  3. Adjust the number of pages to match what's in the FTP.
  4. Create a new blank tab named for the week you're working on; copy from the Generator tab, **paste values only**.
  5. Download the tab as a CSV.
- **Upload:** upload the codesheet into the flyer run → Save Code Sheet → Process Code Sheet.
- **Pricing zones:** once the codesheet finishes (green / Progress: Complete), mark flyer creation complete. If promoted versions share pages you may see a "pages already uploaded" yellow warning — double-check you're using the correct matrix, then select **force processing**.

### Setup QC checklist (owned by DOC)

- Confirm all pages uploaded correctly (Pricing Zone tab → Items View).
- Confirm flyer dates (first page of the flyer).
- **Hide on Hosted.**
- Complete thumbnails (4 Standard).
- Ensure all preview dates are set.
- Complete Setup QC checklist.

## QC specifics

### Box Draw (Low complexity — Auto-Box ON, Box QC bot OFF)
- **Include:** coupons.
- **Exclude:** packaged deals, retailer logo, sign-up page, social media, special weblinks.
- Box each item with its price OR sales story individually.
- **Watch secondary pricing in a product block — box it separately.**

### Tag / Tag QC (Low complexity — Auto-tag ON)
- Brand used for both Box and Tag.
- **Include:** name, pre/postfix, valid dates, description, price, sale story, categories, disclaimer, original price.
- **Exclude:** SKU, URLs.

### Spotchecks
- Standard pricing spotchecks included in the pipeline (20% of pricing zones).

## Post-processing / FQC (owned by DOC)

- Confirm dates against the PDF; confirm availability toggles.
- Thumbnails correct and include the retailer logo.
- All items boxed and tagged; spotchecks complete; previews published and clickable; sessions completed accurately; geography correct.

## Flyer Review (owned by Flex)

- **Flyer Review type: Lite.**
- Check: flyer dates, sessions completed, previews showing correctly (**vertical preview will not work — do not check it**), all items tagged accurately, geography correct, availability toggles correct.
