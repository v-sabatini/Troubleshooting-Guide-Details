## Files & schedule

- **Files received:** Wednesday.
- **Publication cadence:** Available From Wednesday · Valid From Tuesday · Available To Wednesday · Valid To Tuesday.
- **No linking document; no preview date.**

## Upload & setup (owned by DOC)

- **Manual Upload:** Pages Tab → Edit. Select all pages from the SFTP. Files sit in a folder labeled month & date (e.g. `/2024/may/22-28`); pages may be split by store location — usually **British Columbia and Alberta** (e.g. `…/ab` and `…/bc`). Confirm & Upload.
- Group pages via Auto-Group or manual numbers (English pages only). Save & Confirm → **Do NOT process internally.**
- **Pricing Zone Creation:** based on store details in the email — one file set = **Base** version; AB + BC file sets = **two versions**. Add applicable stores (AB/BC for two-version, or Base store set for single).
- Once vendor tasks are available, add this note to **TAG and TAG QC**: apply link to all items `https://bigboxoutletstore.ca/blogs/flyer?utm_source=flipp`.

### Setup QC (owned by Flex)
- Confirm all pages uploaded (Items View); check SFTP for un-uploaded pages.
- Confirm flyer dates (from email). **No Theme, No External Run Name.** Thumbnails 4 Standard.

## ⚠️ Common errors / risk items
- **Auto-Group misorders double-digit pages** — it sorts by first digit, so page 10 lands after page 1. Watch pages 10 and above.
- **Files are usually late**, so the **valid date is often *before* the available date** — this is expected.
- **Look for multiple products** (multi-item boxes).
- **Every item must carry the URL** `https://bigboxoutletstore.ca/blogs/flyer?utm_source=flipp` — check "Items Without a URL" returns nothing.

## QC specifics

### Box Draw (Low; Auto-Box ON, Box QC bot OFF)
- **Exclude:** coupons, packaged deals, retailer logo, sign-up page.
- **Include:** social media, special weblinks.

### Tag / Tag QC (Low; Auto-tag OFF; PDF image auto-select ON)
- **Include:** name, pre/postfix, valid dates, description, price, sale story, categories, disclaimer, original price, URLs. Brand used for box + tag. **Exclude SKU.**
- **URLs:** always apply `https://bigboxoutletstore.ca/blogs/flyer?utm_source=flipp` to all items.

### Image QC
- PDF preferred if clean; otherwise cutouts accepted.

## Post-processing / FQC (owned by DOC)
- Confirm dates from PDF; availability toggles; thumbnails include retailer logo.
- Standard checks (all boxed/tagged, spotchecks 20% of pricing zones, previews clickable, sessions complete, geography correct).
- "Items Without a URL" must be empty; add the flyer URL if any appear.
- **Flyer Review type: Lite** (owned by Flex) — dates, sessions, previews, tagging, no extra autobox boxes, geography (may change WoW per distribution), availability toggles.
