## Upload & setup (owned by DOC)
- **Pages may need to be added to the SFTP by the processor if the client sends files over email.**
- **Manual upload:** Pages Tab → Edit. Select all pages from the SFTP menu (or upload manually from email). Confirm & Upload.
- Once pages listed, Auto-Group or manually enter grouping numbers. **Ensure the correct language is selected — French.**
- Save & Confirm.
- **Pricing zones (bilingual):**
  1. Create **Base** pricing zone in French, select all applicable pages. Save & Next.
  2. Create **"Base CL"** pricing zone in French, select all pages, **check "cross language"**, change PZ language to **English**. Save & Confirm.
  3. Add all stores to both zones.

### Setup QC checklist (owned by DOC)
- Confirm all pages uploaded (Pricing Zone tab → Items View); confirm no un-uploaded pages remain in the SFTP.
- Confirm flyer dates (usually first or last page).
- Complete thumbnails (4 Standard); complete Setup QC checklist.

## QC specifics

### Box Draw (Low complexity — Auto-Box OFF, Box QC bot ON)
- **Include:** packaged deals.
- **Exclude:** coupons, retailer logo, sign-up page, social media, special weblinks.
- Box each item/pricing callout separately.

### Tag / Tag QC (Low complexity — Auto-tag OFF)
- Brand used for both Box and Tag.
- **Include:** name, pre/postfix, valid dates, description, price, sale story, categories, disclaimer, original price.
- **Exclude:** SKU, URLs.
- Standard processing: large title text = Name, plus Price, plus any other text in description. **Use text boxes to capture all needed text.**

### Image QC
- PDF preferred if clean; otherwise cutouts accepted.

### Spotchecks
- Standard pricing spotchecks included (20% of pricing zones).

## Post-processing / FQC
- Item Image QC (owned by DOC).
- Pre-final (owned by DOC): confirm dates against PDF; availability toggles; thumbnails with retailer logo; all boxed/tagged; spotchecks complete; previews published/clickable; sessions completed; geography correct.
