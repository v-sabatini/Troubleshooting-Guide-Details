## Files & schedule
- **Files received:** Wednesday afternoon. Two weekly flyers: Grocery and Boutique.
- Available Tue–Wed; Valid Thu–Wed (2-day preview). Linking document: **Yes**.

## ⚠️ Risk items
- **Scene+ PTS:** all offers with Scene+ must have "Scene+ PTS" tagged in the Sale Story. Some offers don't say "Scene+" and only show points earned — Scene+ still must be tagged. Correct form is exactly **"500 Scene+ PTS"** (not "500 PTS", "500 Scene", "500+ PTS").
- **Dates:** do NOT change dates without confirming with operations. Available Tue–Wed; Valid Thu–Wed.

## Upload & setup (owned by Vendor) — bilingual
**Upload to Hosted only; flyers are cloned to Flipp during FQC.**
1. Pages > Edit > Week > select folder with the publication end date; upload grocery pages to the grocery flyer, boutique to boutique.
2. Toggle files **French** > Save > refresh to confirm all FR.
3. Upload the same files again, toggle **English** > Save.
4. Autogroup > Save and complete.
5. Pricing Zones: EN (English files) + FR (French files); confirm pagination.
6. Add all stores to both EN and FR pricing zones (Grocery Hosted and Boutique Hosted).
7. Wait for sessions. Attach linking document to all vendor tasks for both flyers via FTP (checkmark "mass attachment" + `(+)`).
8. Overview > Edit Details:
   - Hosted runs: available on **Hosted only**, No Theme, no external run name.
   - Flipp runs: available in **Distribution and Flipp only**, No Theme; External Run Name (EN) = "Espace Santé".
9. Confirm flyer dates on PDF pages. Leg heights (pre-set) 55/25. Thumbnails Standard 4 (1065x600 remove white border, pg 1&2; Stock premium pg 1; Storefront carousel premium pg 1&2; organic pg 1).
10. Setup QC checklist; mark autostack complete.

## QC specifics
- **Box Draw (Low; Auto-Box ON, Box QC bot ON; linking doc required for Box/Tag — add to all EN & FR vendor tasks):** exclude coupons, packaged deals, retailer logo/banner, sign-up, social, special weblinks. Group items in boxes by price. Special weblinks (contest banners) get the EN/FR links from the linking doc.
- **Tag / Tag QC (Low; Auto-tag OFF; linking doc required):** include Brand/Name (FR versioning above brand, EN below; brand usually NOT bold), Pre/Postfix (current price /lb and /kg; +tx), Valid Dates, Description (FR desc on FR flyers, EN on EN flyers, non-bold), Price, Sale Story (Scene+ check), Categories, Disclaimer, Original Price, URLs. Exclude SKU.
- **Image QC:** clean PDFs with no shadows + white background; else use cutout.

## Post-processing (owned by Vendor)
- **URL/Links QC:** linking docs exist for Grocery and Boutique (EN + FR links). Draw one box per item on the page > Tag > display type **Link** > file name = exact name from linking doc > URL from linking doc > Save. **Be mindful of EN vs FR links.** Add contest-insert links (EN/FR) when the insert is present. Boutique linking doc usually holds the Voila link.
- **Scene+ check (item search: Sale Story contains "PTS").**

### FQC (owned by Vendor)
- Confirm links, item image QC (clean PDFs else cutout), Scene+ PTS check, outstanding vendor tasks/sessions.
- Pricing zones: confirm iframe and vertical preview interactive; **verify linking-doc links appear in the vertical scroll**. If they don't: re-box/re-tag banners, rerun tile generation, rerun republish, or remove/re-add the affected page(s).
- Flyer sorting (Flyer Type Oldest First): Grocery Live, Grocery Preview, Espace Santé Live, Espace Santé Preview.
- Mark auto-judge complete, then clone.

### Cloning (after FQC of both flyers)
- **Grocery flyer:** Overview > Clone > "Clone to Rachelle Béry → Grocery"; use the pre-created **(Flipp)** run matching the date; Copy Tracking Codes/URLs = No; Clone. Wait for sessions. In the Grocery (Flipp) run, Edit Details > **hide in Hosted**. In pricing zones (EN & FR), remove all "Boutique/Espace Santé" store set → should leave **8 stores**. Run FQC.
- **Espace Santé/Boutique flyer:** same steps, "Clone to Rachelle Béry → Espace Santé", hide in Hosted, remove "Grocery" store set → should leave **94 stores**. Run FQC.
