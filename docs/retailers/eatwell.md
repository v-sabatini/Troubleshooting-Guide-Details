## Files & schedule

- **When files arrive:** Monday. Available From Monday · Valid From Wednesday · Available To Monday · Valid To Tuesday.

## Upload & setup (owned by FLEX)

1. Schnucks FTP → search **EW** → download that week's pages.
2. In the Eatwell flyer run, **manual upload — only EW pages.** Auto-group.
3. **One pricing zone — Base.** Available everywhere. Let sessions run.

**Setup QC:**
- Thumbnails Standard 4 (`Thumbnail_1065_x_600`, `Stock_premium`, `Storefront_carousel_premium`, `Storefront_carousel_organic`).
- Dates: **Valid from 12am; Available from 2:30pm.** No theme. Available everywhere.
- **Key message: "This Week's Big Savings".**
- Geography tab should read "No Stores or FSAs/zips were added or removed".

### ⚠️ Common errors / risk items (retailer-specific)

- **Look for multiple products** in one image/block.
- **Do NOT box or tag the socials.**

## QC specifics

- **Box Draw (Low; Auto-Box ON, Box QC bot OFF).** No linking doc. **Include** coupons, packaged deals, sign-up page. **Exclude** retailer logo, social media, special weblinks.
- **Tag / Tag QC (Low; Auto-tag OFF).** Linking doc required (Tag/QC specific). Include name/brand (if applicable), price/original price (if applicable), pre/postfix (if applicable), valid dates, description, sale story, disclaimer, categories. **Exclude SKU.** URLs = N/A.
  - **Description:** the text below the item name goes into Description (often no sale story or pre/postfix). **Categories:** add Google Category.
  - **Valid dates:** only if a special sale differs from the flyer run. **Disclaimer:** add for limited-time / certain-items-only offers.
- **Image QC:** **use cutout images** (unselect PDF Images and Data Piped to see items with cutouts/no image; a clean white-background PDF may be used if available).

## Post-processing / Final QC

- **Item Category QC (DOC):** "Items without Google Categories" → add categories by item name.
- **Item Image QC (FLEX):** use cutout images.
- **URL/Links QC (FLEX):** download the document in the vendor tab and check the pages exist.
- **FQC (DOC):** overview error-free; correct dates and available-from/valid-from times; themes; key messages; thumbnails, Image QC and Category QC complete; legibility height **50/40**; items/tagged/vendor-QC totals match; page order correct; sessions don't need re-running; vendor tasks complete; geography has no new stores/FSAs (unless told).
- **Flyer Review type: Lite** (owned by FLEX).
