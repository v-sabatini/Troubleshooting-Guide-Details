## Upload & setup (owned by DOC)
- Retrieve the generic codesheet from the Food King shared folder → download the file marked "FOOD KING (UPDATED - USE THIS ONE)".

- **Troubleshooting codesheet error:** open the codesheet and the error page → check whether those pages exist in the FTP.
  - Pages missing → email retailer to send files.

## ⚠️ Common errors / risk items
- **White space on pages:** previews will show large white spaces that require re-slicing those pages.

## QC specifics
- **Box Draw (Low; Auto-Box ON, Box QC bot OFF):** **Include** coupons; **exclude** packaged deals, retailer logo, sign-up page, social media, special weblinks. Coupons/promotions embedded in a coupon are boxed/tagged as an item (promotion in sale story, details in disclaimer).
- **Tag / Tag QC (Low; Auto-tag OFF; SIMP POP — Tag QC not completed):** Brand tag/QC specific. Include name, pre/postfix, valid dates, description, price, sale story, categories, disclaimer, original price; **exclude SKU and URLs.** Name = bold text; description = un-bolded text after the name; prices as in flyer. A category chart is provided in the OneGuide (Toys, Seasonal, Pharmacy, Pets, Outdoor Living, Home Essentials, Health & Beauty, Grocery, Grills, Gifts, Coupon, Beverages, Beer/Wine & Liquor).
- **Image QC:** N/A.
- **Spotchecks:** verify the correct option reflects what is on the page.
