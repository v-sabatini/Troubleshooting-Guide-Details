# Eatwell — Processing Guide

> **Source:** Schnucks OneGuide (Google Doc `1FSSMLwkBmm5svOJ6xzJzBTZKtgiHCkQC9xkHzj4RA2U`), updated Jun 1, 2026. Contacts/credentials omitted.
>
> Eatwell is processed as the **"Eat Well" flyer type within the Schnucks OneGuide.** Notes below cover the Eat Well type.

## Account at a glance

| | |
|---|---|
| Account tier | Tier 3 Standard (Schnucks account) |
| Availability | **Hosted only** |
| Slack channel(s) | `#schnucks` |
| Flyer type(s) & cadence | **Eat Well** (part of Schnucks) |
| Processing | Auto-stack; Flex (FAB tickets); OS (Setup + FQC); no coupons; **Feedel / retailer data services: Yes** |

## Files & schedule

- **When files arrive:** Monday. Available From Monday · Valid From Wednesday · Available To Monday · Valid To Tuesday.

## Upload & setup (owned by FLEX)

1. Schnucks FTP → search **EW** → download that week's pages.
2. In the Eatwell flyer run, **manual upload — only EW pages.** Auto-group.
3. **One pricing zone — Base.** Available everywhere. Let sessions run.

**Setup QC:**
- Thumbnails Standard 4 (`Thumbnail_1065_x_600`, `Stock_premium`, `Storefront_carousel_premium`, `Storefront_carousel_organic`).
- Dates: **Valid from 12am; Available from 2:30pm.** No theme. Available everywhere.
- **Key message: "This Week's Big Savings".**
- Geography tab should read "No Stores or FSAs/zips were added or removed".

### ⚠️ Common errors / risk items (retailer-specific)

- **Look for multiple products** in one image/block.
- **Do NOT box or tag the socials.**

## QC specifics

- **Box Draw (Low; Auto-Box ON, Box QC bot OFF).** No linking doc. **Include** coupons, packaged deals, sign-up page. **Exclude** retailer logo, social media, special weblinks.
- **Tag / Tag QC (Low; Auto-tag OFF).** Linking doc required (Tag/QC specific). Include name/brand (if applicable), price/original price (if applicable), pre/postfix (if applicable), valid dates, description, sale story, disclaimer, categories. **Exclude SKU.** URLs = N/A.
  - **Description:** the text below the item name goes into Description (often no sale story or pre/postfix). **Categories:** add Google Category.
  - **Valid dates:** only if a special sale differs from the flyer run. **Disclaimer:** add for limited-time / certain-items-only offers.
- **Image QC:** **use cutout images** (unselect PDF Images and Data Piped to see items with cutouts/no image; a clean white-background PDF may be used if available).

## Post-processing / Final QC

- **Item Category QC (DOC):** "Items without Google Categories" → add categories by item name.
- **Item Image QC (FLEX):** use cutout images.
- **URL/Links QC (FLEX):** download the document in the vendor tab and check the pages exist.
- **FQC (DOC):** overview error-free; correct dates and available-from/valid-from times; themes; key messages; thumbnails, Image QC and Category QC complete; legibility height **50/40**; items/tagged/vendor-QC totals match; page order correct; sessions don't need re-running; vendor tasks complete; geography has no new stores/FSAs (unless told).
- **Flyer Review type: Lite** (owned by FLEX).

# Ecotone — Processing Guide

## Files & schedule

- **When files arrive / cadence:** ad hoc. No preview date. **Linking document: Yes — for URLs.**

## Upload & setup (owned by FLEX)

- Pages may need to be added to the SFTP by the processor if the client sends files over email.
- **Manual upload:** Pages Tab → Edit → select all pages from the SFTP menu → Confirm & Upload → Auto-Group (or enter grouping numbers); **ensure all pages are selected as French only** → Save & Confirm. **Do NOT Process Internally.**
- **Pricing zone:** create **Base**, select all applicable pages, add all stores.
- **Linking document:** attach the corresponding FTP linking doc to all vendor tasks. **If none, flag to the Coordinator.**

### ⚠️ Common errors / risk items (retailer-specific)

- **Look for multiple products** in one image/block.
- **Multiple colours, one price:** box each image **separately**.

- **Image QC:** PDF preferred if clean; otherwise cutouts accepted.

## Final QC / go-live (owned by FLEX)

- **Pre-FQC:** check URLs — almost all items should have one; if missing, check the link sheet (some items simply aren't listed — then no URL is OK). Confirm dates vs. PDF; availability toggles; thumbnails correct incl. retailer logo.
- Standard FQC checklist.
- **Flyer Review type: Lite** (owned by FLEX).

# El Rio Grande — Processing Guide

> **Source:** El Rio Grande OneGuide (Google Doc `1mwBr1iqODOaWyogl-KeJUP_gz1J3n6eiqo9ZkGQzyEI`), updated Jun 1, 2026. Contacts/credentials omitted.

## Account at a glance

| | |
|---|---|
| Account tier | Tier 3 Standard |
| Availability | **Flipp & Distribution only** |
| Slack channel(s) | `#elriogrande` |
| Hosted URL | elriogrande.net/weekly-specials |
| Flyer type(s) & cadence | **Weekly** |
| Processing | Auto-stack; Flex (Flyer Review); OS (Setup); no coupons; **Feedel / retailer data services: Yes** |

## Files & schedule

- **When files arrive:** Thursday. Available From Wednesday · Valid From Wednesday · Available To Tuesday · Valid To Tuesday.

## Upload & setup (owned by Vendor)

- **Manual upload** (files usually dropped Thursday). Page naming: `Ers1_A_R01` → Ers# = page number, R0# = version. "ALL" in the filename means the page is the same across versions (upload one copy).
- **Only upload pages labelled `P0001, P0002…`** — do NOT upload files without page numbers.
- Create **three pricing zones V1, V2, V3** and insert their respective pages. Add all V1 stores to V1, V2 stores to V2, V3 stores to V3.
- **Setup QC:** available on Flipp & Distributed only; **key message "Our Deals. Your Savings."**; thumbnails Standard 4 (page 2 is wide — don't fill the entire second page with the thumbnail); legibility heights **45/30**.

### ⚠️ Common errors / risk items (retailer-specific)

- **3-Day Sale items** (bottom of page 1): every item in the 3-Day Sale section must have **Sale Story = "3 DAY SALE"** plus **Item Valid From / Item Valid To** dates matching the banner callout — not the full-flyer dates.
- **Store #7:** often not listed in page names, but **must be included in Pricing Zone V1** — add all V1 store-set stores to PZ V1 **including Store #7**; do NOT remove it.

## QC specifics

- **Box Draw (Low; Auto-Box ON, Box QC bot ON).** No linking doc. Box all items with prices (text boxes when needed). **Include** packaged deals. **Exclude** coupons, retailer logo, sign-up page, social media, special weblinks.
- **Tag / Tag QC (Low; Auto-tag ON; PDF Image Auto Selection ON).** No linking doc. Tag all fields as in the flyer. Include name, pre/postfix, valid dates, description, SKU, price, sale story, categories, disclaimer, original price. Brand handled via Box Draw/Box QC. URLs = N/A.
  - **Name:** the **English** (or non-bold) version of the item; brand if applicable.
  - **Description:** the **Spanish** name of the item. If only one language is available, put the larger/bold text in Name and the smaller/non-bold text in Description.
  - **SKU:** use the flyer-provided SKUs if available.
  - **Valid dates:** watch for the "3-DAY SALE" box on page 1 (a section, not the whole page/publication).
  - **Disclaimer:** only enter if it's inside the drawn box; ignore disclaimers at the bottom of the page.
- **Image QC:** prioritize clean **white-background PDFs**; avoid lifestyle/background PDFs (choose the cutout); plated-item images OK if they match the flyer; if the PDF has a large black shadow that doesn't match, choose the cutout.

## Final QC / go-live (owned by Vendor)

- Edit Details: available on Flipp and Distributed only. Thumbnails Standard 4. Page categories (no category on page 1).
- **Check the 3-Day Sale section on page 1 for BOTH versions** — each item has valid dates matching the 3-Day Sale banner and Sale Story = "3 DAY SALE".
- Complete FQC checklist (certain overview errors may be ignored — Save and Complete if they're the only ones).
- **Flyer Review type: Lite** (owned by FLEX).

# El Super Fresh — Processing Guide

| Flyer types | Weekly (single flyer type) |
| Processing | Auto-stack |

## Files & schedule

- **Files received:** Thursday.
- **Cadence:** Available From Wednesday, Valid From Wednesday; Available To / Valid To Tuesday.
- Workflow: Upload & Setup (Flex) → Image QC → FQC (Flex).

## Upload & setup (owned by Vendor)

- Pull the codesheet (xlsx) from the SFTP. **Confirm you pull the correct file — El Super vs. El Super Fresh** (they are distinct).
- Open the codesheet and **delete any extra titled columns (Page 5, Page 6, etc.) that have no page data beneath them.** Save as CSV.
- Upload to the Codesheet tab: **Config name `generic`**; PDF base directory pulled from the SFTP.
- **All toggles ON except Region Assignment and Combine Zones.** Run codesheet.
- After it runs, check the pricing-zones page for correct zones/stores/pages. Mark "Flyer Creation" complete. Check Geo shows **"No Stores or FSAs/zips were added or removed!"**

### Setup QC
- Check SFTP that all pages uploaded.
- Edit Details: **no external run name; hide on "Flipp Hosted" only; no theme;** check run dates against the dates at the bottom of the flyer.
- Thumbnails: **Standard 4** (1065×600 first two pages; stock premium first page; storefront carousel premium first two pages; storefront carousel organic first page).

## QC specifics

### Box Draw (Low; Auto-Box ON, Box QC bot OFF)
- **Include** retailer logo. **Exclude** coupons, packaged deals, sign-up page, social media, special weblinks.
- Box each item block. For buy-this-get-that deals, box each item individually.

### Tag / Tag QC (Low; Auto-tag OFF; PDF image auto-selection OFF)
- **Include** name, pre/postfix, valid dates, description, price, sale story, categories, original price. Brand is box-draw specific. **Exclude** SKU, disclaimer, URLs.
- **⚠️ Item-level valid dates:** items boxed within a dated promo area must carry that promo's item Valid From/To. Example: an item under "2 Días Ofertas De Fin de Semana" dated Nov 23–24 must be tagged Valid From/To Nov 23–24.

### Image QC
- N/A.

### Spotchecks
- Ensure every item has a **Google category and an Analytical category**.

## FQC (owned by Flex)
- Spotchecks if required; QC thumbnails Standard 4 (stock premium, storefront carousel premium/organic).
- Edit Details: available everywhere, no external run name, run dates match the PDF.
- Flag missing pages or geography changes to the full-time team.
- **Flyer Review type: Lite.**

## Out-of-processing
- See the El Super / El Super Fresh 2025 Publication & Ad-Hoc Requests guidelines (in the OneGuide) for BF comms and ad-hoc requests.

# Extra Foods — Processing Guide

> **Source:** Extra Foods OneGuide (Google Doc `1IxIXitBbFuSXAoxQEyySebhdJaPWHuADwsQsXa7WhNY`). Contacts/credentials omitted.

## Account at a glance

| | |
|---|---|
| Account tier | Tier 3 Standard |
| Availability | All platforms |
| Slack channels | `#loblawops`, `#loblaw-lcl` |
| Hosted URL | nofrills.ca (Loblaw banner) |
| Flyer types | Weekly (flyer 5994) |
| Processing | Auto-stack |
| Who's involved | Flex (Flyer Review); OS (Setup); DOC processes; no coupons; Strategic Ops — yes, Feedel/retailer data services |

## Files & schedule

- **Files received:** Monday. Codesheets labeled `WK__ RCWC EF FINAL CODES`; download and upload to the LCL Flex Upload folder, and update the Flex Tracker.
- **Cadence:** Available From Wednesday, Valid From Thursday; Available To / Valid To Wednesday (1-day consumer preview). Set a preview date for the Monday before live (for OS to prioritize).

## Upload & setup (manual)

- **Only refer to the EF tab** for page numbers, store changes, URLs.
- Select all Extra Foods files under the correct week; upload as English pages; number per codesheet — **usually 1 page + a HOTM flap page.** Check the Merchant FTP that all pages pulled in.
- Pricing zone: **Base** — usually 1 PZ, sometimes 2. Add stores: EF store set → Add all (2 stores as of Sept 2024). If a 2nd PZ, adjust stores per codesheet.
- Edit Details: external run name format `Weekly flyer Valid Thursday, July 14 - Wednesday, July 20`; no theme.

## QC specifics

### Box Draw (Low; Auto-Box ON, Box QC bot ON; linking doc required)
- **Include** coupons, packaged deals. **Exclude** retailer logo, sign-up page, social media, special weblinks.
- Box only around the item where there's a unique price. **Box banners linking to nofrills.ca; do NOT box/tag Facebook, Twitter, etc.**

### Tag / Tag QC (Medium; Auto-tag OFF; linking doc required)
- Include name, pre/postfix, valid dates, description, SKU, price, sale story, categories, disclaimer, original price. **Exclude URLs.** Brand is box-draw specific.
- **Name:** ALL CAPS, `Brand Product Name, Quantity` (always a comma before quantity). **Tag all info in FRENCH AND ENGLISH, separated by "/".** Product name is bold in the flyer.
- **Description:** plain (non-bold) text; capitalize first letter; metrics like `2.56/kg`; "Product of…", "No. 1 grade", "frozen", "selected varieties".
- **SKU:** only when in flyer. Multibuy items need Postfix Text and Postfix Amount.
- **Valid dates:** apply item date overrides only when a promo sales story on the item calls for it.
- **PC Optimum:** tag as normal item; sale story includes the PC Optimum points offer.
- **Images — Rule 1:** cleanest PDF (white/clear background); no shadows/lifestyle → don't use PDF. **Rule 2:** PDF for meat/seafood/cheese only if packaged; if not packaged, use cutout.
- **Page-level categories** during box draw for all pages **except front cover** (Deli & Ready Meals, Bakery, Meat & Seafood, Dairy & Eggs, Drinks, Baby Needs, Household Supplies, Beauty & Skincare, Medicine & Health, Frozen, Produce).

### Post-processing (owned by DOC)
- Item Category QC, Item Image QC, URL/Links QC, SKU QC, Ad-Hoc QC.

## Pre-Final QC / FQC (owned by DOC)
- Storefront: merge flap page to the right; if two flap pages, merge them; if one, merge with front/cover P01.
- Ledge heights 40/30.
- **⚠️ Image QC — MEAT & SEAFOOD:** do NOT select PDF images of raw meat/seafood; OK if in a package with a label; otherwise use cutout.
- Thumbnails Standard 4, start where the logo is; **do NOT include flap pages** even if merged to cover.
- **⚠️ Risk:** number of pages varies across zones — modify thumbnail start position accordingly.
- Item view: all items boxed. Check URLs from the codesheet; box/tag links written on PDFs (e.g. PC Children's Charity box). Known links: PC Optimum (pcoptimum.ca), Extra Foods (extrafoods.ca).
- Page categories 1–2 per page except page 1.
- Item searches: categories blank; SKU blank; URL blank where SKU present (fill article number if URL present but article number 1 blank).
- FQC: Available Wed–Wed (1-day preview), Valid Thu–Wed, available everywhere, external run name set. Log flyer ID in the LCL Tracker by 2:30 Monday.

## Flyer Review
- **Type: Lite.**

## ⚠️ Live-date common errors
- **URL** leading to a different item → flag.
- **Item quantities** put into the description → flag.
