## Upload & setup (owned by Vendor)

- **Manual upload:** Pages tab → Edit → select all pages from the SFTP menu. **Folder named by the flyer's valid date — always use the lowercase folder** (never the uppercase one). Confirm & upload → Auto-Group → Save & Complete.
- **Pricing zone:** create one zone called "Base"; add all stores; Save & Complete.

### Setup QC checklist
- Confirm all pages uploaded — in the SFTP nothing should remain except the multi-page PDF (uppercase filename not ending in `P####`). Flag missed pages to the FT team.
- Confirm flyer valid dates match page 1.
- Standard 4 thumbnails.
- **Geography tab: 0 changes to stores/FSAs** — flag ANY changes to the FT team (continue the checklist, but flag 100% of discrepancies).
- Platform toggles: available on all platforms.

## ⚠️ Common errors / risk items

- No retailer-specific risk items were filled in. Key watch-items: use the **lowercase** SFTP folder on upload, and flag **any** geography change immediately.

## QC specifics

- **Box Draw (Low; Auto-Box ON, Box QC bot OFF):** exclude coupons, packaged deals, retailer logo, sign-up page, social media, special weblinks.
- **Tag / Tag QC (Low; Auto-tag ON):** include image (always a clean PDF if available), brand, name, pre/postfix, valid dates, description, price, sale story, categories, disclaimer, original price. **Exclude SKU and URLs.**
- Spotchecks: standard, included in pipeline.

## FQC / flyer review (owned by Vendor)

- **Pre-final QC:** confirm valid dates against PDF; available everywhere; thumbnails drawn with retailer logo; all items boxed and tagged; previews published and clickable; geography consistent with last week (flag 100% of store/FSA discrepancies to FT Ops — non-blocking).
- Complete FQC checklist.
- **Flyer Review type: Lite.**
