## Files & schedule

- **Files received:** Monday, uploaded to the FTP. Sometimes a Word doc with specific linking is included, usually called out in the notification email.
- **Cadence:** generally the first of the month (can differ between ON and West). Available From Monday, Valid From Tuesday; Available To Monday, Valid To Tuesday.

## Upload & setup (owned by Flex)

- Two flyers: **West** (under the "West" flyer type — files have **"MWP"** in the name) and **ON** (under the "flyer" flyer type).
- **Manual upload**, all English pages. One PZ (Base); add stores by region — **West flyer → West stores; ON flyer → ON stores.**
- Standard 4 thumbnails. **Available dates = valid dates.** Internal/external run name = the callout on the first page. No theme. Attach the linking document.

## QC specifics

### Box Draw (Low; Auto-Box ON, Box QC bot ON; no linking doc)
- **Exclude** coupons, packaged deals, retailer logo, sign-up page, social media, special weblinks.
- Draw a box around each item. **Items stacked together → box each separately** (do not group).
- **DEAL ZONE items must ALL be boxed separately.**
- One item with different styles/types in a block (e.g. 4 dresses, one price) → **one box for the whole block.**

### Tag / Tag QC (Low; Auto-tag OFF; linking doc required)
- **Include** name, pre/postfix, valid dates, categories, disclaimer, original price, URLs. **Exclude** brand, description, SKU, **and sale story** (Brand = No).
- **Name:** bigger/bold font; copy exactly as shown (capitalization included). **Do NOT include sewing-pattern callouts** (e.g. "McCall's 7596") in name/description or tag them as items — they are not part of any promotion.
- **No SKU** for any item.
- **Valid dates:** always from the flyer; if an item differs, use its exact date.
- **Sale Story:** has a sale callout/discount (e.g. "50% off our regular prices").

### Image QC
- Prioritize PDFs; cutouts where necessary. Add text where the item isn't clear. **No black/grey backgrounds.**

## FQC (owned by DOC — same process for West and ON)
- Mark autostack spotcheck complete; check Geography; confirm all items boxed/tagged (do a links QC if a linking doc is provided).
- Sessions: mark items **In-Store Only**; check vertical preview for clickable items.
- Toggles: available everywhere, external run name = the PDF callout, no theme.
- **⚠️ The West flyer must be set to Available/Valid at 3:00 AM.**
